## 维护规则

1. **新文档只能放进两类**：`文档/版本文档/` 或 `文档/教学文档/`；总纲在 `文档/代码总纲/00-代码总纲.md`。不要再往 `文档/` 根目录加零散文件。
2. **一篇文档只回答一类问题**：版本记录不写原理，讲义不写发布步骤；交叉处用链接。
3. **版本明细写 `CHANGELOG.md`**：`版本记录.md` 只保留可读摘要。
4. **改代码同步总纲**：新增关卡、子系统、命令分支时，更新 [代码总纲](代码总纲/00-代码总纲.md) 对应调用堆栈。
5. **提交前跑** `pwsh -File tools\docs-check.ps1`（校验文档里引用的源码路径存在）。
