# 术语表（Glossary）

> 用法：第一次遇到不认识的词，先查这里；每条给"一句话定义 + 直觉 + 代码位置"。
> 代码位置写的是**文件 + 符号**，不写行号——行号会随重构变化，符号更稳。

## 渲染 / RHI

| 术语 | 英文 | 一句话定义 | 直觉 | 代码 |
|---|---|---|---|---|
| RHI | Render Hardware Interface | 渲染器与图形 API 之间的薄封装层 | 目标是换后端只改这一层；现状见 [引擎架构](../引擎架构.md) §5.3 | `engine/src/rhi/` |
| 交换链 | SwapChain | 管理前后缓冲与 Present 的队列 | 双缓冲翻页 | `rhi/Device.cpp` `Device::Init/EndFrame` |
| 后备缓冲 | BackBuffer | 当前要显示的那张纹理 | 显示器的"画布" | `rhi/Device.h` |
| RTV / DSV | Render Target View / Depth Stencil View | 把纹理"绑定成可渲染目标"的视图 | 给画布装个画框 | `rhi/RenderTarget.cpp` |
| 输入布局 | Input Layout | 顶点数据在显存里的字段顺序契约 | 表格的列定义 | `renderer/Renderer.cpp` `kPbrLayout` |
| 顶点/索引缓冲 | Vertex / Index Buffer | 顶点数组 / 顶点下标数组 | 点表 + 连线表 | `renderer/Mesh.cpp` |
| 常量缓冲 | Constant Buffer | 每帧/每物体传给 shader 的小块常量 | 给 GPU 的参数页 | `rhi/Buffer.h` `ConstantBuffer<T>` |
| NDC | Normalized Device Coordinates | 裁剪空间除以 w 后的 [-1,1]³（D3D z∈[0,1]） | 屏幕的"标准坐标" | 第 4 讲 |
| 视图矩阵 | View Matrix | 世界 → 相机空间 | 把世界搬到相机眼前 | `renderer/Camera.cpp` `View()` |
| 投影矩阵 | Projection Matrix | 相机空间 → 裁剪空间 | 透视"近大远小" | `Camera::Projection()` |
| MVP | Model-View-Projection | 三个矩阵的合成 | 一套模具 | 第 4 讲 |
| 视锥剔除 | Frustum Culling | 用 6 个平面剔除视野外物体 | 只画镜头里的东西 | `Math.h` `Frustum::IntersectsAABB` |
| AABB / OBB | Axis-Aligned / Oriented Bounding Box | 轴对齐 / 有向包围盒 | 盒子的两种摆法 | `Math.h` `AABB` |
| 实例化 | Instancing | 一次 draw 画多个同网格物体 | 盖章 | `Renderer::DrawBatches` |
| 法线矩阵 | Normal Matrix | `(M⁻¹)ᵀ`，正确变换法线 | 法线的专用模具 | `Renderer::BuildBatches` |
| sRGB | sRGB Color Space | 显示器的非线性编码 | 开方存储省精度 | 第 7 讲 |
| 线性空间 | Linear Space | 光照计算所在的空间 | 光可以相加 | 第 5/7 讲 |
| HDR | High Dynamic Range | 亮度可超过 1 的缓冲 | 留得住太阳 | `RenderTarget` RGBA16F |
| 色调映射 | Tone Mapping | 把 HDR 压到 [0,1] | 相机曝光曲线 | `shaders/Post.hlsl` `ACESFilm` |

## 光照

| 术语 | 英文 | 定义 | 直觉 | 代码 |
|---|---|---|---|---|
| BRDF | Bidirectional Reflectance Distribution Function | 入射方向到出射方向的反射比例 | 表面怎么反光 | 第 5 讲 |
| 辐亮度 | Radiance | 单位面积单位立体角的功率 | 眼睛看到的"亮" | `PBR.hlsl` |
| 辐照度 | Irradiance | 单位面积接收的功率 | 太阳晒在皮肤上的能量 | `PBR.hlsl` |
| 微表面 | Microfacet | 把表面看成大量小镜面 | 磨砂金属的微观结构 | `PBR.hlsl` `DistributionGGX` |
| NDF | Normal Distribution Function | 微表面法线朝向的分布 | 高光有多"散" | `DistributionGGX` |
| Smith G | Geometry Term | 微表面互相遮挡的比例 | 掠射角变暗 | `GeometrySchlick` |
| Fresnel / F0 | 菲涅尔项 / 基础反射率 | 反射率随角度变化；F0 是正对时的反射率 | 水面边缘更亮 | `FresnelSchlick` |
| 能量守恒 | Energy Conservation | 反射+吸收=入射，不会凭空变亮 | 金属没有漫反射 | `kd = (1-F)(1-metallic)` |
| IBL | Image Based Lighting | 用环境贴图做光照 | 用一张全景图当灯 | 未实现（第 21 讲） |

## 阴影

| 术语 | 英文 | 定义 | 直觉 | 代码 |
|---|---|---|---|---|
| 阴影贴图 | Shadow Map | 从光源渲染的深度图 | 光源视角的照片 | `shaders/Shadow.hlsl` |
| PCF | Percentage Closer Filtering | 多次比较后平均，柔化阴影边缘 | 阴影边缘的"毛边" | `PBR.hlsl` `SampleShadow` |
| 阴影失真 | Shadow Acne | 自遮挡产生的条纹 | 脸上长黑条纹 | `bias` 参数 |
| 彼得潘 | Peter-panning | 偏移过大导致阴影与物体分离 | 影子飘在空中 | 第 6 讲 |
| 级联阴影 | Cascade Shadow Map | 按距离分几级阴影图 | 近处清晰远处模糊 | 未实现 |
