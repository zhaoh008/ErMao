# 第 21 讲：全局光照近似与光照探针（现状 + 设计）

> 对应 GAMES104 第 21 讲（动态 GI / Lumen）。
> 状态：本工程**只有 `World` 的半球环境光（天/地两色）**，没有光照探针、没有 SSAO/SSGI、没有 IBL 镜面反射。球谐和探针在本讲是**尚未实现的设计**，不是已有功能。

---

## 0. 背光面不是纯黑，墙角却不是更暗

把太阳转到物体背后，背光面仍然能看出颜色和轮廓；但把两个墙面凑成墙角，墙角**并没有**比周围更暗。这两件事听起来矛盾：

- 背光面不黑，是因为还有**间接光**：天空、地面、其他物体把光反射过来，照到了太阳照不到的地方；
- 墙角应该更暗，是因为墙角能“看到”的天空更少，接收到的间接光更少——这需要**可见性/遮蔽**，本工程没有算。这里的全局光照（Global Illumination，GI）指的就是“直接光之外、由其他表面反射来的光”。

所以“环境光从哪来”这个问题，准确的回答是：真实场景里来自**所有其他表面的反射**；本工程里来自一个**人为设定的半球颜色**。本讲先给最便宜的常数环境光，再看它为什么像贴纸，然后引入半球光照、辐照度和探针的层级。最后会明确：哪些是现在跑的代码，哪些只是设计。

---

## 1. 最省的版本：常数环境光

先假设“环境”在各个方向一样亮，记环境辐亮度为 `L_amb`。对 Lambert 表面，出射辐亮度是：

```
L_o = albedo/π · ∫_Ω L_amb · (N·ω) dω
```

`L_amb` 是常数，可以提出积分；而 `∫_Ω (N·ω) dω = π`，于是：

```
L_o = albedo/π · L_amb · π = albedo · L_amb
```

也就是说，**常数环境光不需要再除 π**：辐照度积分产生的 `π` 正好和 BRDF 的 `1/π` 抵消。最简实现就是：

**概念伪代码（不是本工程源码）**

```hlsl
float3 ambient = ambientColor * ambientIntensity;
color += ambient * albedo;
```

它只回答“有多少环境光”，完全不回答“从哪个方向来”。这就是下面所有问题的根源。

## 2. 常数环境光具体地失败

### 2.1 所有朝向一样亮

`ambient * albedo` 里没有法线。球体的上半部分和下半部分、朝天的桌面和朝地的桌底，环境项完全相同。关掉太阳后，整个物体变成一个**没有立体感的剪影**。

### 2.2 物体像贴纸

真实环境里，朝上的面看到天空，偏蓝偏亮；朝下的面看到地面，偏暗偏暖。常数环境光把这种方向差异抹掉了，物体边缘没有“环境色溢出”，看起来像贴上去的。

### 2.3 暗部没有方向感

太阳的明暗交界线还在，但交界线之外的暗部是一块平色。美术想表达“这个角落更暗”“这个物体靠近墙，环境光被挡住”，都没有手段。

### 2.4 墙角不会更暗（没有遮蔽）

环境项直接加在颜色上，没有乘任何可见性。墙角、桌底、物体接触处应该更暗，但代码里这些位置和开阔地得到的 `ambient` 一模一样。这就是第 0 节“墙角不更暗”的原因。

### 2.5 金属发黑

金属没有漫反射，环境贡献主要应该来自**环境镜面反射**。本工程的环境项只乘 `albedo`（漫反射），没有环境镜面采样，所以金属在背光处几乎全黑——第 5 讲的材质图里能看到这个现象。

## 3. 半球环境光：本工程当前的做法

把环境近似成“上半球一个颜色、下半球一个颜色”，再按法线的 `y` 分量插值：

**源码节选（`engine/shaders/PBR.hlsl` 末尾）**

```hlsl
float hemi = N.y * 0.5 + 0.5;       // 法线朝上=1，朝下=0
float3 ambient = lerp(gAmbientDownExposure.rgb, gAmbientUpCount.rgb, hemi) * gMisc.y;
color += ambient * baseColor * (1.0 - metallic * 0.7);
```

参数来自 `World`（`World.h` 默认值，`World::BuildRenderScene` 填进 `RenderScene`）：

```
ambientUp        = (0.30, 0.38, 0.52)
ambientDown      = (0.10, 0.09, 0.08)
ambientIntensity = 0.9
```

编辑器“光照”面板可以改这三个值（`EditorUI.cpp` 的“环境光(天)/环境光(地)/环境强度”）。

### 3.1 它为什么恰好是“线性插值”

假设上半球是均匀辐亮度 `L_up`，下半球是均匀辐亮度 `L_down`，且没有遮挡。对法线 `N`，辐照度是两半球贡献之和：

```
E(N) = ∫_上半球 L_up·(N·ω)dω + ∫_下半球 L_down·(N·ω)dω
```

对“均匀上半球”积分，结果恰好是 `π·L_up·(1+N.y)/2`；下半球对称，是 `π·L_down·(1−N.y)/2`。合起来：

```
E(N) = π · [ (1+N.y)/2 · L_up + (1−N.y)/2 · L_down ]
```

再乘 Lambert 的 `albedo/π`：

```
L_o = albedo · [ (1+N.y)/2 · L_up + (1−N.y)/2 · L_down ]
    = albedo · lerp(L_down, L_up, N.y*0.5+0.5)
```

这正是代码里的 `lerp(down, up, hemi)`。所以这个“看起来像美术公式”的写法，其实是**两段均匀半球环境 + Lambert** 的精确解（在没有遮挡的前提下）。`π` 又一次被抵消，代码里不需要写。

### 3.2 代入一组数

用上面的默认值，分别取 `N.y = 1, 0.5, −1`，再乘 `albedo = 0.8`：

| `N.y` | 上半球权重 | 下半球权重 | 环境项（乘 albedo 后） |
|---|---|---|---|
| `1`（朝上） | 1.0 | 0.0 | `(0.216, 0.2736, 0.3744)` |
| `0.5` | 0.75 | 0.25 | `(0.180, 0.2214, 0.2952)` |
| `−1`（朝下） | 0.0 | 1.0 | `(0.072, 0.0648, 0.0576)` |

计算过程（以 `N.y=0.5`、红通道为例）：`0.75×0.30 + 0.25×0.10 = 0.25`，乘 `0.9` 得 `0.225`，再乘 `0.8` 得 `0.18`。朝上和朝下的红通道差 3 倍，蓝通道差约 6.5 倍，方向感主要来自这个比例。

如果改用“常数环境光”（取上下平均值 `(0.20,0.235,0.30)`），所有法线都得到 `(0.144,0.1692,0.216)`：朝上的面会比现在暗，朝下的面会比现在亮，方向信息被抹平。

`(1.0 - metallic*0.7)` 是一个人为修正：金属只拿 30% 的环境漫反射，避免金属看起来像“带颜色的塑料”。它不是物理公式，也没有替代环境镜面反射；`Skinned.hlsl` 里同样的环境项甚至没有这个因子，两个着色器在这一处并不完全一致。

| SSAO（屏幕空间环境光遮蔽） | 屏幕空间深度采样，算遮蔽 | 墙角/接触处变暗 | **尚未实现的设计** |
| SSGI（屏幕空间全局光照） | 屏幕空间射线找间接光 | 屏幕内的一次反弹 | **尚未实现的设计** |

## 5. 辐照度与球谐：如果要存“方向分布”

### 5.1 辐照度是什么

**辐照度（Irradiance，`E`）**是单位面积接收到的功率，单位 W/m²；它是对所有入射方向积分后的量，已经“压掉”了方向信息：

```
E(N) = ∫_Ω L(ω) · (N·ω) dω
```

对 Lambert 表面，`L_o = albedo/π · E(N)`。所以环境光的核心任务就是：**给定法线 N，快速算出 E(N)**。

### 5.2 球谐展开

**球谐函数（Spherical Harmonics，SH）**是一组定义在球面上的基函数，可以把任意方向分布 `L(ω)` 展开成系数：

```
L(ω) ≈ Σ_{l=0..2, m=-l..l} c_lm · Y_lm(ω)
c_lm = ∫_Ω L(ω) · Y_lm(ω) dω
```

- `l=0`：1 个常数项，表示平均亮度；
- `l=1`：3 个一阶项，表示“主要从哪个方向来”（类似主光方向）；
- `l=2`：5 个二阶项，表示更细的方向变化。

漫反射只需要“余弦卷积后的辐照度”，而余弦核在 SH 空间是对角的，所以可以用同一组系数直接算：

```
E(N) ≈ Σ_l A_l · Σ_m c_lm · Y_lm(N)
A_0 = π,  A_1 = 2π/3,  A_2 = π/4
```

`A_l` 是余弦卷积的特征值（Ramamoorthi & Hanrahan 2001，[SH]）。阶数越高，`A_l` 衰减越快，所以漫反射这种“低频”结果用前 3 阶（9 个系数）就能表示得很好；常见说法是 9 个系数可把漫反射误差压到约 1%。

> 约定：上面的 `c_lm` 用的是实数归一化 SH 基（`Y_00 = 1/(2√π)`）。如果换一套基或换归一化，系数和 `A_l` 的写法会变，但“投影 → 乘特征值 → 重建”的流程不变。

### 5.3 一个自洽性检查

若环境是常数 `L(ω)=L_0`，则 `c_00 = L_0·√(4π) ≈ 3.5449·L_0`，重建 `E = A_0·c_00·Y_00 = π·L_0`，与第 1 节的 `E=πL` 一致。这说明“常数环境 → `albedo·L`”不是巧合，而是 SH 的 `l=0` 项。

## 6. 如果要做探针：数据流与步骤（尚未实现的设计）

下面全部是**设计**，本工程没有这些文件和函数。写出来是为了说明“要存什么、谁算谁、怎么接回现有 shader”，不是宣称已经实现。

**设计伪代码（尚未实现）**

```text
关卡
  └─ 探针位置（手动放点，或按网格自动铺）
       └─ 每个探针捕获 6 面立方体（例如 128×128）
            └─ 对每个 texel 的方向 ω 做投影：
                 c_lm += L(ω) · Y_lm(ω) · dω
            └─ 存 9 个 float3 系数（108 字节）+ 位置/半径
                 └─ 渲染时：找最近的 4/8 个探针，按距离或四面体插值
                      └─ E(N) = Σ A_l c_lm Y_lm(N)
                           └─ 环境项 = albedo/π · E(N)
```

如果要在本工程落地，需要动的位置大致是：

1. **数据**：`World` 增加探针数据（位置、半径、9 个系数），`World::BuildRenderScene` 把它填进 `RenderScene`；
2. **捕获**：`Renderer` 增加一个“从探针位置渲染 6 面”的 Pass。当前 `RenderTarget` 只支持 2D 颜色目标，没有立方体贴图/立方体 RTV，需要新增资源与 shader；
3. **投影**：CPU 或 compute shader 把 6 面颜色按立体角权重累加成 9 个系数；静态场景可以离线烘焙，动态场景要定期重算；
4. **着色**：`PBR.hlsl` 把现在的 `lerp(up,down,N.y)` 替换成“采样探针 → 重建 E(N) → 乘 albedo/π”；保留半球环境光作为没有探针时的回退；
5. **遮蔽（可选但影响很大）**：SSAO 或探针可见性，用来让墙角变暗；没有它，探针只会让颜色有方向，墙角仍然不暗。

几个工程取舍：

- **SH 不是唯一解**：也可以直接存 6 面 irradiance cubemap（采样更贵、但高频更好），或用 DDGI 的动态探针；SH 的优点是 9 个系数很小、插值便宜，缺点是只能表达低频，镜面反射需要另外的预过滤环境图；
- **探针数量与更新频率**是主要成本：静态烘焙可以很密，动态重捕获要限帧、限分辨率；
- **插值**：最近探针会“跳变”，三线性/四面体插值更平滑，但需要探针排成规则网格或做 Delaunay 类结构；
- **不要为了“有 GI”而上探针**：如果画面只需要上下方向感，当前的半球环境光已经够；先确认问题到底是“没有方向”还是“没有空间变化/没有遮蔽”。

## 8. 实验（本次未实际运行）

本环境是 Linux，**没有运行 exe**；环境光没有命令行参数，只能在编辑器“光照”面板里调：

```bat
build\bin\ErMao.exe --level thirdperson --play --frames 120
```

1. 把“环境强度”从 0.9 调到 0：背光面变成纯黑，只剩太阳直接光；现象与原理的对应是“环境项被乘了 0”，不是灯坏了；
2. 把“环境光(天)”调成和“环境光(地)”相同的颜色：`lerp` 退化成常数，球体上下方向感消失，物体看起来更像贴纸；
3. 把“环境光(天)”调蓝、“环境光(地)”调暖：朝上的面偏蓝、朝下的面偏暖，验证 `N.y` 的权重方向；
4. 把某个物体的 `metallic` 从 0 拖到 1：它拿到的环境漫反射变成 30%，暗部更黑；因为本工程没有环境镜面，金属不会像真实金属那样反射天空。

不符合预期时的排查入口：所有物体暗部一样黑，先看 `ambientIntensity` 是否为 0；上下方向反了，检查 `ambientUp/ambientDown` 是否接反；改了编辑器颜色但画面不变，检查 `World::BuildRenderScene` 是否把字段填进了 `RenderScene`；金属和环境光都正常但墙角仍不暗，那是没有 AO，不是环境光参数的问题。

## 9. 自测题

1. 为什么常数环境光不需要再除 π？**答**：`E=∫L·cosθ dω=πL`，Lambert 的 `L_o=albedo/π·E=albedo·L`，两个 π 抵消；见第 1 节。
2. 半球环境光的 `lerp(down, up, N.y*0.5+0.5)` 在什么模型下是精确的？对应 SH 的哪几项？**答**：在“上半球、下半球各是均匀辐亮度，且没有遮挡”的模型下精确；重建出的 `E(N)` 只有 `l=0` 加一个只沿 `y` 的 `l=1` 项，没有 `l=2` 及更高阶。
3. 为什么漫反射只用 SH 前 3 阶？镜面反射为什么需要更高阶？**答**：余弦卷积核是低频的，`A_l` 随 `l` 快速衰减，前 3 阶已能表示绝大部分漫反射；镜面反射的 lobe 更窄、方向性更强，需要更高频的表示（预过滤环境图/更高阶 SH），9 个系数不够。
4. SSAO 的采样半球怎么构造？**答**：用像素法线构造 TBN 基，在切线空间里对半球（例如余弦加权）采样一组方向，变换到世界/视图空间，比较深度判断遮挡；本工程没有实现。
5. 本工程墙角为什么不变暗？**答**：环境项只按 `N.y` 插值，没有可见性/遮蔽项；墙角的法线和开阔地一样时，环境光完全一样。

## 10. 练习（思考 + 改坏）

1. 只用常数环境光（删掉 `lerp`，改成固定颜色）：**预期**所有物体暗部一样亮，球体失去上下方向感，像贴纸。
2. 把上下环境光对调：**预期**朝上的面变暗、朝下的面变亮，物理上反了；这是检查“有没有把 up/down 接反”的快速实验。
3. 把 `ambientIntensity` 设为 0：**预期**背光面变成纯黑，只剩太阳直接光；可以用来确认直接光/环境光的边界。
4. 把 `(1.0 - metallic*0.7)` 改成 `1.0`：**预期**金属的环境漫反射变多，金属会显得更“粉”，但因为没有环境镜面，仍然不会像真实金属。
