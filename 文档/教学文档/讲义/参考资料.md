# 参考资料总表

> 讲义里用 `[键]` 引用，这里是完整条目。优先列官方规范、教材和正式论文；
> 博客/工程笔记只用于“工程做法”的补充，不单独支撑核心数学结论。
> 标注“未实现的设计”的章节，参考条目只说明方向，不代表本工程已经实现。

## 图形学与渲染

- **[RTR4]** Akenine-Möller, Haines, Hoffman, Pesce, Iwanicki, Hillaire. *Real-Time Rendering*, 4th ed., CRC Press, 2018. https://www.realtimerendering.com/
- **[PBRT]** Pharr, Jakob, Humphreys. *Physically Based Rendering: From Theory to Implementation*, 4th ed., MIT Press, 2023. https://pbr-book.org/
- **[GAMES101]** 闫令琪. *GAMES101 现代计算机图形学入门*（变换/光栅化/光线追踪/BRDF），2020. https://games-cn.org/intro-graphics/
- **[GAMES104]** 王希等. *GAMES104 现代游戏引擎：从入门到实践*（Booming Tech / Piccolo Engine）. https://games104.boomingtech.com/
- **[COOK]** Cook, Torrance. *A Reflectance Model for Computer Graphics*. ACM TOG, 1982.
- **[SMITH]** Smith. *Geometrical Shadowing of a Random Rough Surface*. IEEE Trans. Antennas and Propagation, 1967.
- **[SCHLICK]** Schlick. *An Inexpensive BRDF Model for Physically-based Rendering*. Computer Graphics Forum, 1994.
- **[KARIS]** Karis. *Real Shading in Unreal Engine 4*. SIGGRAPH 2013 Course Notes.
- **[SH]** Ramamoorthi, Hanrahan. *An Efficient Representation for Irradiance Environment Maps*. SIGGRAPH 2001.
- **[SHADOW]** Williams. *Casting Curved Shadows on Curved Surfaces*. SIGGRAPH 1978.
- **[SHADOWVOL]** Crow. *Shadow Algorithms for Computer Graphics*. SIGGRAPH 1977.
- **[PCF]** Reeves, Salesin, Cook. *Rendering Antialiased Shadows with Depth Maps*. SIGGRAPH 1987.
- **[ACES]** Academy Color Encoding System（官方）. https://acescentral.com/ ；本工程使用的拟合曲线：Narkowicz. *ACES Filmic Tone Mapping Curve*, 2016. https://knarkowicz.wordpress.com/2016/01/06/aces-filmic-tone-mapping-curve/
- **[TONE]** Reinhard, Stark, Shirley, Ferwerda. *Photographic Tone Reproduction for Digital Images*. SIGGRAPH 2002.
- **[CULL]** Frustum culling：RTR4 §19.2；GPU Driven：Wihlidal. *Optimizing the Graphics Pipeline with Compute*, GDC 2016.
- **[SPRITE]** 2D sprite batching：RTR4 §18.4；正交投影：RTR4 §2.6.
- **[QUAT]** Shoemake. *Animating Rotation with Quaternion Curves*. SIGGRAPH 1985.
- **[SLERP]** 同 [QUAT]（四元数球面插值最早由 Shoemake 系统描述）。

## 动画与蒙皮

- **[LBS]** Magnenat-Thalmann, Laperrière, Thalmann. *Joint-dependent Local Deformations for Hand Animation and Object Grasping*. Graphics Interface 1988.
- **[SKIN]** Kavan, Collins, Žára, O'Sullivan. *Skinning with Dual Quaternions*. I3D 2007.

## 物理、碰撞与数值

- **[SEMI]** Hairer, Lubich, Wanner. *Geometric Numerical Integration*, 2nd ed., Springer, 2006.
- **[SAT]** Gottschalk, Lin, Manocha. *OBBTree: A Hierarchical Structure for Rapid Interference Detection*. SIGGRAPH 1996.
- **[GJK]** Gilbert, Johnson, Keerthi. *A Fast Procedure for Computing the Distance Between Complex Objects in Three-Dimensional Space*. IEEE J. Robotics and Automation, 1988.
- **[FIXED]** Fiedler. *Fix Your Timestep!*, 2004. https://gafferongames.com/post/fix_your_timestep/ （工程做法；固定步长的稳定性结论以 [SEMI] 为准）
- **[RTREE]** Guttman. *R-Trees: A Dynamic Index Structure for Spatial Searching*. SIGMOD 1984.

- **[AI]** Millington. *Artificial Intelligence for Games*, 3rd ed., CRC Press, 2018.
- **[BT]** Isla. *Handling Complexity in the Halo 2 AI*. GDC 2005.
- **[BTBOOK]** Colledanchise, Ögren. *Behavior Trees in Robotics and AI: An Introduction*. CRC Press, 2018.

## 网络（本工程未实现）

- **[LAG]** Bernier. *Latency Compensating Methods in Client/Server In-game Protocol Design and Optimization*. GDC 2001.
- **[SNAP]** Claypool, Claypool. *Latency and Player Actions in Online Games*. Communications of the ACM, 2005.
- **[NET]** Glazer, Madhav. *Multiplayer Game Programming: Architecting Networked Games*. Addison-Wesley, 2015.

## 引擎架构、编辑器与数据

- **[GEA]** Gregory. *Game Engine Architecture*, 3rd ed., CRC Press, 2018.（分层、主循环、反射/序列化、资源、并发等）
- **[REFLECT]** 反射与序列化的工程做法见 [GEA] 第 5、6、16 章；C++ 没有标准反射，本工程用字段描述表实现。
- **[IMGUI]** Cornut. *Dear ImGui: Bloat-free Immediate Mode Graphical User Interfaces for C++*. https://github.com/ocornut/imgui
- **[JSON]** ECMA-404. *The JSON Data Interchange Format*, 2013. https://www.json.org/
- **[JOB]** Blumofe, Leiserson. *Scheduling Multithreaded Computations by Work Stealing*. JACM, 1999.
- **[AMDAHL]** Amdahl. *Validity of the Single Processor Approach to Achieving Large Scale Computing Capabilities*. AFIPS 1967.

## 音频

- **[AUDIO]** PCM 与采样定理：Oppenheim, Schafer. *Discrete-Time Signal Processing*, 3rd ed., Pearson, 2010. 混音：Pirkle. *Designing Audio Effect Plugins in C++*, 2nd ed., Routledge, 2019.
- **[XAUDIO2]** Microsoft. *XAudio2 APIs*（Windows SDK 开发文档）. https://learn.microsoft.com/windows/win32/xaudio2/xaudio2-apis-portal

## 文件格式与图形 API

- **[OBJ]** Wavefront OBJ 格式没有公开的正式规范，常用说明：https://paulbourke.net/dataformats/obj/ （本工程只支持 `v/vn/vt/f` 的最小子集）
- **[VK]** Khronos. *Vulkan 1.3 Specification*. https://registry.khronos.org/vulkan/
- **[VKSAMPLES]** Khronos. *Vulkan Samples*（官方示例，含同步与交换链的最小流程）. https://github.com/KhronosGroup/Vulkan-Samples
- **[PART]** Reeves. *Particle Systems—A Technique for Modeling a Class of Fuzzy Objects*. SIGGRAPH 1983.
