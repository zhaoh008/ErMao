# 学习指南：怎么用这套代码和讲义

> 受众：计算机科学与技术本科毕业、会 C++、但没写过引擎。
> 目标：**能指着代码说出“这一步在干什么、为什么这么写”**，而不是背公式。

---

## 1. 先跑起来（30 分钟）

```bat
build.bat
build\bin\ErMao.exe
```

进去以后按顺序试一遍，建立“输入 → 现象”的直觉：

| 操作 | 看什么 |
|---|---|
| 右键拖动 / WASD | 编辑器相机（和游戏相机是两套） |
| 左键点物体 | 世界大纲高亮、检视器出现字段（反射驱动，第 14 讲） |
| 拖 Gizmo / 按 F | 位移/旋转/缩放与聚焦（第 13 讲） |
| F5 | Play-In-Editor，场景快照/回滚（第 14 讲） |
| F2 / F4 | 线框 / 阴影开关（第 4/6 讲） |
| F11 / F12 | 隐藏编辑器 / 截图 |

然后跑三个命令行实验：

```bat
build\bin\ErMao.exe --test-serialize --frames 2                :: 场景 JSON 往返（第 14 讲）
build\bin\ErMao.exe --smoke --frames 200 --level thirdperson   :: 角色移动（第 15 讲）
build\bin\ErMao.exe --level skinning --play --noeditor --frames 120 --screenshot skin.png  :: 蒙皮（第 8 讲）
```

构建/排错见 [构建与运行](../版本文档/构建与运行.md)。

## 2. 读什么、按什么顺序

**先读 [代码总纲](../代码总纲/00-代码总纲.md) §1–§3**：建立“分层 + 启动 + 每帧”的全局，再往下钻。
不要从讲义 `01` 一路读到 `22`，按“你现在想搞懂什么”选路线（详见 [教学大纲](README.md) 与 [讲义索引](讲义/README.md)）：

| 目标 | 路线 |
|---|---|
| 看懂引擎骨架 | 第 0 课 → 01 → 02 → 03 → 04 → 14 → 15 |
| 能改渲染 | 04 → 05 → 06 → 07 → 08 → 22 |
| 能做玩法 | 03 → 14 → 15 → 10 → 11 → 16 → 17 |
| 想改代码 | 代码总纲 §10 函数索引 + §11 速查表 |

每讲的讲解顺序：**现象/问题 → 最简实现 → 具体失败 → 正式方案 → 源码 → 可验算例子 → 进阶数学/取舍 → 实验与自测**。
第一次读可以跳过“进阶”，但别跳过“失败”：先看懂原来的办法为什么不够，后面的概念才有着落。
读的时候手边开着编辑器，看到“实验”就真的去点一下。

## 3. 读代码的三个问题

对每一段代码，只回答三个问题（答不出来就说明这里需要补文档）：

1. **输入是什么、输出是什么？**
2. **它在整条链路的哪个环节？**（输入 → 更新 → 构建 RenderScene → 渲染 → 后处理）
3. **如果删掉它，屏幕上会少什么？**

举例：`Renderer::BuildBatches`
1. 输入：`RenderScene.items` + 相机；输出：按 mesh/texture 分好的批次 + 实例数据；
2. 环节：渲染之前、ShadowPass 之前；
3. 删掉：什么都画不出来（没有 draw call）。

**追栈方法**（断点打哪、回调/虚函数/多线程怎么认）见 [代码总纲 §12](../代码总纲/00-代码总纲.md)。

### 建议的代码阅读顺序

| 顺序 | 文件 | 你会看到 |
|---|---|---|
| 1 | `runtime/main.cpp` → `runtime/Engine.cpp` | 引擎怎么启动、主循环长什么样 |
| 2 | `core/Math.h` | 向量/矩阵/四元数/视锥，全部手写 |
| 3 | `rhi/Device.cpp` | D3D11 设备与交换链的最小初始化 |
| 4 | `renderer/Renderer.cpp` | 阴影 → 天空 → 不透明 → 粒子 → 调试 → 后处理 |
| 5 | `engine/shaders/PBR.hlsl` | GGX、阴影采样、调试视图 |
| 6 | `scene/World.cpp` | 对象管理、组件调度、JSON 存档 |
| 7 | `scene/Components.cpp` | 反射字段描述（Inspector 的数据来源） |
| 8 | `editor/ImGuiLayer.cpp` → `editor/EditorUI.cpp` | 即时模式 UI、Dock 布局与面板 |
| 9 | `physics/PhysicsWorldSim.cpp` | 积分、碰撞、冲量 |
| 10 | `ai/NavGrid.cpp` → `ai/Agents.cpp` | A* 与感知/状态机 |
| 11 | `core/JobSystem.cpp` | 分块并行 |

## 5. 怎么提问（给你自己的建议）

你提到会把疑问记下来再批量问。为了让回答更准，记录时带上这三样：

```
【问题】为什么半隐式欧拉比显式欧拉稳？
【我读到哪】L10 §3 / physics/PhysicsWorldSim.cpp Step()
【我卡在哪】(具体哪一步推导/哪一行代码不理解)
```

问题会按主题补进对应讲义，并把高频问题记到本节——
**同一个问题被问两次，就说明讲义这里没讲清楚，应该改讲义而不是只回一句话。**

## 6. 这套东西的边界（别被误导）

- **渲染**：单线程前向管线 + 可选 GPU 剔除；没有 IBL/延迟渲染/阴影级联；Vulkan 只到阶段一；
- **物理**：教学级球/盒碰撞，没有 GJK/EPA、CCD、关节、布料/破坏；
- **网络**：只有设计讨论（L18），没有网络层；**GI**：只有半球环境光近似（L21），没有探针/SSGI；
- **平台**：只有 Windows 二进制，Linux 只给源码包；
- **编辑器**：没有撤销栈，属性编辑直接改对象；
- **测试**：以 `--test-serialize` / `--smoke` / `--import` / `--package` 自检为主，没有完整单元测试。

这些都在每讲的“差距”里写明。**知道边界，比多背十个公式有用。**
