# 2D 幸存者：职业选择、教学关与 20 层关卡

> 本文档对应 2D 幸存者 0.5.2 的玩法调整：进入先选职业、第 1 层教学关、2–20 层随机通关条件。
> 数值与文案以 `engine/src/game/Survivors.h` / `Survivors.cpp` 为准。

## 1. 进入流程

```
小程序启动 / 主菜单“开始游戏”
        ↓
出战准备（选择职业，未选时“开始教学”禁用）
        ↓
第 1 层：教学关（四步操作 + 35 秒实战）
        ↓
层间结算（显示下一层随机条件、恢复 25% 生命）
        ↓
第 2…20 层：随机通关条件
        ↓
第 20 层通过 → 胜利结算
```

- 不再默认预选“游侠”；`m_playerClass = -1` 表示未选择。
- 主菜单“继续游戏”仍直接读档，不受影响。
- H5 截图入口 `?play=1` 可用 `&class=0|1|2` 指定职业；微信启动走“先选职业”。

## 2. 职业与角色立绘

| 职业 | 立绘（角色立绘文件夹） | 基础武学 | 成长方向示例 |
|---|---|---|---|
| 游侠 | 桃花谷·郭蛇雕 | 箭矢 | 散射 Lv.1→2 向、Lv.3→6 向、Lv.5→12 向；攻速/攻击/范围继续强化 |
| 剑士 | 华山派·令狐啸 | 回旋刃 | Lv.4→3 刃、Lv.10→5 刃、Lv.20→8 刃；环绕半径随等级扩大 |
| 法师 | 神木派·莫愁姐 | 火球 | Lv.5→2 发、Lv.9→3 发、Lv.17→5 发；爆炸范围随等级扩大 |

- 玩家角色只使用**静态立绘**：不播行走序列帧，不做走路起伏，只按移动方向左右翻转（“转向”）。
- 立绘原画朝向写在 `SurvivorsClassDef::artFacesRight`，翻转时按该值校正。
- 怪物保留 idle/run/death 序列帧与行走起伏。
- 三种职业的基础技能、被动数值与旧版一致；换的只是立绘与选人页展示。

## 3. 教学关（第 1 层）

教学关不再计时自动推进，而是用**四步操作门槛**保证玩家真的学会：

| 步骤 | 操作要求 | 完成后 |
|---|---|---|
| 第一步 · 移动角色 | WASD / 拖动屏幕，移动超过 1.2 个世界单位 | 勾选“移动”，进入下一步 |
| 第二步 · 拾取灵气 | 走到玩家右侧的灵气光点旁拾取（锁定不吸附） | 勾选“拾取灵气” |
| 第三步 · 习得新法术 | 走到绿色光点旁拾取“雷霆”（强制给雷霆，和面板成长示例一致） | 勾选“新法术” |
| 第四步 · 强化本命法术 | 走到强化光点旁拾取本命法术强化（箭矢散射/回旋刃/火球） | 勾选“强化” |

- 未完成当前操作时：**冻结刷怪、关卡计时、掉落保底和宝箱**，清空场上敌人，玩家持续无敌；只保留移动，所以不会因为不会操作而失败。
- 完成一步后：清单打勾、显示“步骤完成”和勾选标记 1.5 秒，然后自动进入下一步。
- 四步完成后：进入 35 秒怪潮实战；教学面板切换为“训练完成 · 怪潮来了”，展示本命法术和雷霆的等级成长方向，并放出密集弱怪潮，让玩家直接体验满屏技能清场的爽点。
- 教学面板始终展示成长方向示例：
  - 职业本命法术：见第 2 节表格；
  - 雷霆：Lv.3 双雷、Lv.7 四雷、Lv.17 九雷，范围随等级扩大。
- 教学关怪物强度固定为生命 0.45×、速度 0.75×、伤害 0.35×；不刷增益宝箱和精英。

## 4. 20 层与随机通关条件

- 总层数 `kSurvivorsFloorCount = 20`；第 1 层固定教学，第 2–20 层进入时随机抽一种条件。
- 条件池（5 种，尽量不与上一层重复）：

| 条件 | 目标随层数成长 | HUD 显示 |
|---|---|---|
| 存活 | `60 + (层数-1)×20` 秒，±12% 抖动（第 20 层约 7–8 分钟） | 存活 1:23 / 3:00 |
| 击杀 | `40 + (层数-1)×13` 只 | 击杀 63 / 120 |
| 精英 | `2 + (层数-1)×0.5` 名；本层精英刷新间隔缩短到约 6.5–9 秒 | 精英 1 / 3 |
| 拾取经验 | `30 + (层数-1)×10` 枚 | 拾取经验 12 / 60 |
| 武学成长 | 全部已拥有武学的等级之和 `8 + (层数-1)×2` 级 | 武学等级 8 / 30 |

- 通关条件的随机数使用独立的 `m_stageRng`（`std::random_device` 播种），每次进入都不同。
- 层间结算页显示本层条件、本局总击杀/总用时，以及**下一层的随机条件**；点击“进入下一层”后：
  - 清空场上敌人、箭、宝石、掉落与宝箱；
  - 恢复 25% 生命，给 1.5 秒无敌；
  - 武学、等级、技能强化、抽奖 buff 全部保留；
  - 强度按 `30 + (层数-1)×40 + 本层时间` 作为压力时间，层数越高刷怪与怪物属性越强。
- 第 20 层通过后进入胜利结算（“挑战成功 / 通关二十层”）；死亡则是失败结算并显示到达层数。

## 5. 界面调整

- **仙侠主题**：按 `D:\GameEngine\game\xianxia-design` 参考重做配色——暖宣纸面板、青玉主色、朱砂强调、深绿正文；主菜单改为宣纸留白 + 朱砂标题，网页加载页同步换色。
- **按钮/进度条/技能槽/雷达/设置滑条**：改为宣纸底 + 青玉描边；生命条朱砂、经验条青玉；雷达内部由黑底改为宣纸底，敌人红点/掉落绿点/宝箱褐点。
- **角色居中**：相机看向角色身体中心（脚底上方约 1.25 个世界单位），而不是脚底，人物在屏幕上视觉居中。
- **技能高度**：箭矢、火球、回旋刃、棱镜光束改为从身体/手部高度绘制（不再贴地），避免“像用脚放技能”的观感。
- **教学提示字号/对比度**：分步面板用 29–34px 深绿标题、17–19px 正文、青玉勾选；步骤完成用绿色大标题 + 勾选线。
- 出战准备页三张职业卡、手机竖屏三行卡片、HUD 层数/条件进度、层间结算与 20 层胜利结算沿用 0.4.0 布局。
- 字体子集扩充到覆盖新增文案；重新生成命令：
  `python3 tools/make_ui_font_subset.py --font /path/to/wqy-microhei.ttc`
