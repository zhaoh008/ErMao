# 2D 幸存者：职业选择、教学关与 20 层关卡

> 本文档对应 2D 幸存者 0.4.0 的玩法调整：进入先选职业、第 1 层教学关、2–20 层随机通关条件。
> 数值与文案以 `engine/src/game/Survivors.h` / `Survivors.cpp` 为准。

## 1. 进入流程

```
小程序启动 / 主菜单“开始游戏”
        ↓
出战准备（选择职业，未选时“开始教学”禁用）
        ↓
第 1 层：教学关（55 秒）
        ↓
层间结算（显示下一层随机条件、恢复 25% 生命）
        ↓
第 2…20 层：随机通关条件
        ↓
第 20 层通过 → 胜利结算
```

- 不再默认预选“游侠”；`m_playerClass = -1` 表示未选择。
- 主菜单“继续游戏”仍直接读档，不受影响。
- H5 截图入口 `?play=1` 可用 `&class=0|1|2` 指定职业；微信启动走“先选职业”。

## 2. 职业与角色立绘

| 职业 | 立绘（角色立绘文件夹） | 基础武学 | 成长方向示例 |
|---|---|---|---|
| 游侠 | 桃花谷·郭蛇雕 | 箭矢 | 散射 Lv.1→2 向、Lv.3→6 向、Lv.5→12 向；攻速/攻击/范围继续强化 |
| 剑士 | 华山派·令狐啸 | 回旋刃 | Lv.4→3 刃、Lv.10→5 刃、Lv.20→8 刃；环绕半径随等级扩大 |
| 法师 | 神木派·莫愁姐 | 火球 | Lv.5→2 发、Lv.9→3 发、Lv.17→5 发；爆炸范围随等级扩大 |

- 玩家角色只使用**静态立绘**：不播行走序列帧，不做走路起伏，只按移动方向左右翻转（“转向”）。
- 立绘原画朝向写在 `SurvivorsClassDef::artFacesRight`，翻转时按该值校正。
- 怪物保留 idle/run/death 序列帧与行走起伏。
- 三种职业的基础技能、被动数值与旧版一致；换的只是立绘与选人页展示。

## 3. 教学关（第 1 层，55 秒）

教学关的目标不是“活下来”，而是让玩家在 55 秒内经历一次完整的爽感循环：

1. **移动/自动攻击**：`WASD` 或拖动屏幕；武学自动锁定最近敌人。
2. **拾取与升级**：击杀掉经验宝石与强化，走近拾取；升级提升基础属性。
3. **武学成长**：第 16 秒自动解锁“雷霆”，教学面板展示成长方向：
   - 职业基础武学：见上表；
   - 雷霆：Lv.3 双雷、Lv.7 四雷、Lv.17 九雷，范围随等级扩大。
4. **手动拾取新武学**：第 32 秒在玩家附近放一个绿色“新技能”光点，必须走过去拾取（最多 5 个武学）。
5. **满屏清场**：第 42 秒放出密集弱怪潮，配合已解锁的武学让玩家直接看到“很多小怪 + 满屏技能”的爽点。
6. 55 秒后自动通过，进入层间结算。

教学关的怪物强度固定为生命 0.45×、速度 0.75×、伤害 0.35×，数量多、威胁低；不刷增益宝箱和精英。

## 4. 20 层与随机通关条件

- 总层数 `kSurvivorsFloorCount = 20`；第 1 层固定教学，第 2–20 层进入时随机抽一种条件。
- 条件池（5 种，尽量不与上一层重复）：

| 条件 | 目标随层数成长 | HUD 显示 |
|---|---|---|
| 存活 | `60 + (层数-1)×20` 秒，±12% 抖动（第 20 层约 7–8 分钟） | 存活 1:23 / 3:00 |
| 击杀 | `40 + (层数-1)×13` 只 | 击杀 63 / 120 |
| 精英 | `2 + (层数-1)×0.5` 名；本层精英刷新间隔缩短到约 6.5–9 秒 | 精英 1 / 3 |
| 拾取经验 | `30 + (层数-1)×10` 枚 | 拾取经验 12 / 60 |
| 武学成长 | 全部已拥有武学的等级之和 `8 + (层数-1)×2` 级 | 武学等级 8 / 30 |

- 通关条件的随机数使用独立的 `m_stageRng`（`std::random_device` 播种），每次进入都不同。
- 层间结算页显示本层条件、本局总击杀/总用时，以及**下一层的随机条件**；点击“进入下一层”后：
  - 清空场上敌人、箭、宝石、掉落与宝箱；
  - 恢复 25% 生命，给 1.5 秒无敌；
  - 武学、等级、技能强化、抽奖 buff 全部保留；
  - 强度按 `30 + (层数-1)×40 + 本层时间` 作为压力时间，层数越高刷怪与怪物属性越强。
- 第 20 层通过后进入胜利结算（“挑战成功 / 通关二十层”）；死亡则是失败结算并显示到达层数。
