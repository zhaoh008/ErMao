**可复现验证**

```bat
build.bat
build\bin\ErMao.exe --test-serialize --frames 3
build\bin\ErMao.exe --smoke --frames 200 --level thirdperson
build\bin\ErMao.exe --demo --frames 420 --screenshot demo.png
pwsh -File tools\docs-check.ps1
```

### 已知限制（诚实清单）

- **只有 Windows 二进制**：渲染后端是 D3D11；Linux 导出的是源码包，不假装能直接跑。
- **Vulkan 只到阶段一**：能画三角形并截图，还没迁渲染 Pass。
- **网络、完整 GI 只有设计**：L18 / L21 标注为设计，不是已实现功能。
- **资产管线简单**：OBJ / PNG / WAV / 程序化资源；没有 DCC 导出器、材质图、动画压缩。
- **编辑器没有撤销栈**；属性编辑直接改对象。
- **测试以自检命令为主**：序列化、冒烟、导入、打包、文档引用；数学/JSON 单元测试待补。

## 3. 逐版本说明

### v0.1 骨架

- 窗口 / D3D11 设备 / 交换链 / 后备缓冲；
- `World` + `GameObject` + `Component`，Transform、MeshRenderer、Camera、Light；
- 反射驱动的 JSON 场景序列化；
- 固定步长主循环、输入边沿、日志与计时。

> v0.1 的历史没有单独入库，仓库里能追溯的第一个可运行状态是 v0.2。

### v0.2 编辑器

- 放弃第一版自制 UI，换 **Dear ImGui docking**：Dock 布局、离屏视口、世界大纲、检视器、资源浏览器、控制台、统计、设置；
- 第三人称关卡与角色控制器（弹簧臂、WASD、跳跃、鼠标环视）；
- 反射驱动 Inspector：组件字段自动出控件；
- 修掉审核 P0「输入边沿全部失效」及 P1/P2 一批问题（[修复记录](修复记录.md)）。

### v0.3 可玩 Demo

- 「刷怪竞技场」：`Health / Combat / Projectile / Enemy` 组件 + 波次导演；
- 球-AABB 碰撞、3D 头顶血条、主菜单/暂停/失败结算；
- 资源浏览器缩略图、位移 Gizmo、F 聚焦；
- Windows 游戏包 + Linux 源码包；
- 序列化字节级自检；R4–R8 收尾。

### v0.4 讲义化

- 26 篇讲义体系（L00 + GAMES104 主线 + 术语表 + 参考资料）；
- 每讲「数学依据 → 代码位置 → 可复现实验 → 自测题」；
- 离线 HTML 学习站（单文件、侧边栏、搜索、图片放大）；
- 骨骼蒙皮、动画混合、物理、导航/行为树、JobSystem、GPU Driven。

### v0.5 2D

- `Camera2D` + `Sprite.hlsl` + 按贴图合批 + UV 序列帧；
- 「二毛幸存者」2D 像素游戏（移动、索敌、射击、掉落、升级、波次）；
- `game.cfg` 让游戏包直接进关卡；2D/3D 两种游戏包。

### v0.6 3D

- 3D 幸存者：XZ 平面移动、第三人称俯视跟随、外部 OBJ 角色/亡灵/墓碑；
- `AssetManager::GetMeshAsset` 懒加载 OBJ，`World` 识别路径式网格/贴图；
- 粒子支持贴图 + 加法混合；
- 2D/3D 游戏包补齐。

### v0.7 音频 + Vulkan

- XAudio2 + WAV/PCM：2D/3D 幸存者接入开枪/命中/拾取/升级/死亡音效，暂停菜单调音量/静音；
- Vulkan 阶段一：instance → device → Win32 surface → swapchain → render pass → pipeline → SPIR-V 三角形 → present → 截图；
- 每讲补「数学依据与参考资料」，总表 [参考资料](../教学/讲义/参考资料.md)。

### v0.8 AI 优先

- `--script commands.json --json-out report.json`：无头完成建场景、加组件、改字段、导资产、存盘、截图、打包；
- `--validate` 输出结构化校验；
- 命令集：`scene.*` / `object.*` / `component.add|set|get` / `assets.import|list` / `level.build` / `camera.set` / `screenshot` / `package.game` / `validate`；
- Git 工作流、`.githooks`、GitHub Actions（构建 + 冒烟 + 文档引用检查）。

### v0.8.1 – v0.8.6 工程收尾

- **v0.8.1**：`setup.bat` / `setup.ps1` 一键依赖检查；无 Vulkan SDK 用宏隔离；干净 clone 验证。
- **v0.8.2**：编辑器「关卡」菜单、资源浏览器内置关卡、`levelKind` 存档恢复；2D 地面从 1680 个地砖改为 1 个精灵。
- **v0.8.3**：`CMakePresets.json`、CLion 工具链配置、Ninja 产物路径。
- **v0.8.4**：首版调用栈文档。
- **v0.8.5**：调用栈文档改为「大纲优先」（每节先给调用树，算法细节指向讲义）。
- **v0.8.6**：文档体系收敛为「版本文档 + 教学文档」，新增代码总纲与时序图；删除重复的博客规划。

## 5. 版本号与标签

- 语义化版本 `MAJOR.MINOR.PATCH`；每个版本对应一个可运行状态；
- 里程碑标签 `v0.2.0` … `v0.8.0`（`git tag -n`；本仓库导入时未带标签，可按 CHANGELOG 补打）；
- 游戏包版本由 exe 旁的 `game.cfg` 决定默认关卡，命令行参数优先；
- 文档与代码同仓：改了功能要同时更新本页、`CHANGELOG.md` 和 [代码总纲](../00-代码总纲.md)。
