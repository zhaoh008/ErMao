# 构建、运行与排错

> 目标：**一台干净的 Windows 电脑，从 clone 到跑起来不超过 10 分钟**。
> 代码从哪进、每帧做什么，见 [代码总纲](../00-代码总纲.md)；怎么学，见 [学习指南](../教学/学习指南.md)。

## 1. 环境要求

| 项 | 版本 | 说明 |
|---|---|---|
| Windows | 10 / 11 x64 | 需要 D3D11 / DXGI / WIC / XAudio2 |
| Visual Studio | 2022（MSVC v143） | 必须勾选「使用 C++ 的桌面开发」 |
| Windows SDK | 10.0.19041 以上 | VS 安装器里勾选 |
| CMake | ≥ 3.20 | VS 自带亦可；本机用 CLion 的版本 |
| 显卡 | D3D11 Feature Level 11_0 | 无独显自动回退 WARP 软光栅 |
| Vulkan SDK | 可选 | 只有 `--vulkan-test` 需要；不装也能构建 |

> 引擎只依赖 **Dear ImGui**（随仓库分发），没有包管理器、不需要联网拉第三方库。

## 2. 一键构建

### 2.1 第一次：`setup.bat`

```bat
setup.bat                 :: 检查/安装依赖 → 构建 → 冒烟
setup.bat -WithVulkan     :: 顺便安装 Vulkan SDK
setup.bat -NoBuild        :: 只检查依赖
```

脚本按顺序检查：系统架构 → Git（可选）→ VS 2022 + C++ 工作负载 → Windows SDK → CMake
（缺失时用 winget，或下载便携版到 `.tools\cmake`）→ Vulkan SDK（可选）→ 构建 → 30 帧冒烟。
日志在 `setup.log`。

### 2.2 日常：`build.bat`

```bat
build.bat            :: Release
build.bat Debug      :: Debug（D3D11 调试层 + 断言）
```

它负责：找 VS → `vcvars64` → CMake 生成 VS 工程 → `msbuild` → 把 `shaders/` 和 `assets/` 拷到 exe 旁边。

产物：`build\bin\ErMao.exe`（自包含，可整个目录拷走）。

### 2.3 CMake 预设 / 命令行

```bat
cmake --preset vs2022
cmake --build --preset vs2022-release

:: Ninja（需先进入 MSVC 环境）
call "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Auxiliary\Build\vcvars64.bat"
cmake --preset ninja-msvc-release
cmake --build --preset ninja-msvc-release
```

预设：`vs2022` / `ninja-msvc-debug` / `ninja-msvc-release`（`CMakePresets.json`）。

## 3. 运行

```bat
build\bin\ErMao.exe          :: 编辑器（默认加载刷怪竞技场）
run.bat                      :: 先 build.bat，再启动
```

编辑器里按 **F5** 进入 Play，Esc 暂停。打包后的游戏目录直接双击 `<游戏名>.exe` 或 `run.bat`。

### 3.1 命令行参数

| 参数 | 作用 |
|---|---|
| `--level <kind>` | `thirdperson` / `arena` / `survivors` / `survivors3d` / `skinning` / `cull` / `demo` / `empty` |
| `--play` | 启动即进入 Play（游戏相机 + 物理 + AI） |
| `--noeditor` | 不绘制编辑器 UI |
| `--frames N` | 跑 N 帧后自动退出（自动化验证） |
| `--screenshot path.png` | 第 N 帧保存截图后退出 |
| `--demo` / `--demo2d` / `--demo3d` | 一键演示：无编辑器 + 自动开局 |
| `--script commands.json` | AI 无头命令（见 [AI 开发指南](../教学/AI开发指南.md)） |
| `--json-out report.json` | 命令结果输出 |
| `--validate` | 只做结构化校验 |
| `--package windows\|linux` | 引擎包自检 |
| `--package-game windows\|linux` | 游戏包自检 |
| `--vulkan-test` | Vulkan 阶段一自检（无 SDK 时提示不可用） |
| `--audio-test` | 依次播放 8 个音效 |
| `--test-serialize` | 场景 JSON 往返自检 |
| `--smoke` | 脚本化移动/跳跃自检 |
| `--import <path>` | 导入 OBJ 自检 |
| `--debugview N` | 0 正常 / 1 阴影系数 / 2 世界法线 / 3 基础色 / 5 阴影贴图 |
| `--roughness R` / `--metallic M` | 覆盖全场景材质（生成对比图） |
| `--noshadows` / `--no-gpu-cull` | 关闭阴影 / GPU 剔除（教学对比） |

例：

```bat
build\bin\ErMao.exe --play --noeditor --frames 150 --screenshot docs\screenshots\play.png
build\bin\ErMao.exe --demo3d --frames 300 --screenshot demo3d.png
```

### 3.2 游戏包配置

exe 旁的 `game.cfg` 决定默认关卡与模式，命令行参数优先：

```ini
level=survivors3d
editor=0
play=1
```

## 4. 换一台电脑 / 离线环境

- **有网**：`setup.bat` 一条命令。
- **内网/离线**：VS 2022 用「创建脱机安装」布局目录；CMake 下载 zip 解压到 `.tools\cmake`；
  Vulkan SDK 可以不装（D3D11 是主路径）；第三方依赖已 vendored，不需要联网。
- **验证干净 clone**：

```bat
git clone <repo> D:\_ermao_fresh
set VULKAN_SDK=
cd /d D:\_ermao_fresh && setup.bat
```

## 5. 在 CLion / Visual Studio 里打开

### 5.1 CLion（最容易踩坑）

1. `Settings → Build, Execution, Deployment → Toolchains`：启用 **Visual Studio 2022**（x64），
   取消 MinGW / Cygwin / WSL；
2. `Settings → CMake`：删掉旧 profile，`+` 选 **`vs2022`** 预设（或 Generator=`Visual Studio 17 2022`，x64）；
3. `Reload CMake Project`；
4. Run Configuration 的 **Working directory** 设为 `$CMakeCurrentBuildDir$/bin`（资源在 exe 旁边），
   Program arguments 可填 `--demo2d`。

CLion 的 CMake 命令带 `--debugger` 是它自己的调试包装，不是报错原因。

### 5.2 Visual Studio

`文件 → 打开 → CMake`，选择仓库根目录；启动项选 `ErMao`，工作目录设为 `build\bin`。
或先 `cmake --preset vs2022` 生成 `.sln` 再用 VS 打开。

### 5.3 为什么不能用 MinGW

D3D11 / WIC / XAudio2 / D3DCompiler 都是 Windows SDK 的 MSVC 导入库，HLSL 要运行时 `D3DCompile`；
CMake 检测到非 MSVC 会直接给出可操作错误，而不是让你面对上百个编译错误。

## 6. 常见问题

| 报错 / 现象 | 原因 | 处理 |
|---|---|---|
| `cmake 不是内部或外部命令` | CMake 不在 PATH | 跑 `setup.bat`，或把 CMake 加 PATH |
| `MSB8020 / 找不到 v143 工具集` | VS 没装 C++ 工作负载 | VS Installer 勾「使用 C++ 的桌面开发」 |
| `无法打开包括文件: "windows.h"` | 没装 Windows SDK | VS Installer 勾 Windows SDK |
| `C1083: 无法打开包括文件`（Vulkan） | 没装 Vulkan SDK | 用 v0.8.1+（宏隔离）或 `setup.bat -WithVulkan` |
| `C4819: 文件包含不能在当前代码页中表示的字符` | 源码 UTF-8 + 非中文 locale | 已加 `/utf-8`；更新代码 |
| `LNK1104: 无法打开文件 ErMao.exe` | 上次程序还在运行 | 结束 `ErMao.exe` 再构建 |
| `No CMAKE_CXX_COMPILER could be found`（CLion） | Toolchain 没选 / 用了 MinGW | 换 Visual Studio 工具链；删 `cmake-build-*` 后 Reload |
| 能启动但黑屏 / 资源加载失败（CLion） | 工作目录不在 exe 旁边 | Run Configuration 的 Working directory 设为 `.../bin` |
| 启动黑屏 / 窗口一闪而过 | 着色器路径 / 驱动问题 | 看 exe 同目录 `ErMao.log`；确认 `shaders/` 在 exe 旁 |
| 中文显示成方块 | 精简版 Windows 缺「Microsoft YaHei」 | 装中文字体 |
| 帧率很低 | 阴影/后处理/GPU 剔除开销 | Stats 面板看 draw call、三角形数与 GPU 时间 |
| 编辑器里拖了物体，重启又变回去 | 关卡代码优先 | 点「保存」写入 `assets/scenes/*.ermao.json`，再用「文件 → 打开场景」恢复 |
| 路径含空格/中文导致奇怪错误 | 老工具链问题 | 仓库放在 `D:\GameEngine` 这类纯英文路径 |

## 7. 验证清单

```bat
setup.bat
build\bin\ErMao.exe --frames 30 --noeditor
build\bin\ErMao.exe --test-serialize --frames 3
build\bin\ErMao.exe --smoke --frames 200 --level thirdperson
build\bin\ErMao.exe --demo2d --frames 120
build\bin\ErMao.exe --demo3d --frames 120
build\bin\ErMao.exe --audio-test --frames 160
build\bin\ErMao.exe --vulkan-test          :: 没装 SDK 时提示不可用，不算失败
pwsh -File tools\docs-check.ps1
```

全部退出码为 0 即环境 OK。CI 同样跑：CMake 构建 → 文档引用检查 → 30 帧冒烟。

## 8. 目录约定

| 路径 | 内容 |
|---|---|
| `engine/src/<模块>/` | 源文件，头文件与实现同目录 |
| `engine/shaders/` | HLSL，运行时编译，改完重开 exe 生效 |
| `engine/assets/` | 贴图 / 模型 / 场景 JSON / 音频 |
| `build/bin/` | 构建产物（exe + `assets/` + `shaders/`） |
| `docs/screenshots/` | 验证截图 |
| `dist/` | 打包输出 |
