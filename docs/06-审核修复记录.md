## 一、P0：阻断级

### P0-1 所有按下/松开边沿判定失效 ✅ 已修

**原因**：`Poll()` 已经把按键写进 `s_down[]`，紧接着 `Input::Update()` 把 `s_down` 拷进 `s_prev`，
于是 `IsKeyPressed = down && !prev` 永远为假。

**修复**（`platform/Input.h/.cpp`、`runtime/Engine.cpp`）：

```cpp
// 边沿在回调里产生，不再事后比对
void Input::OnKey(int vk, bool down, bool repeat) {
    if (down && !s_down[vk]) s_pressed[vk] = true;   // 新按下
    if (!down && s_down[vk]) s_released[vk] = true;  // 新松开
    s_down[vk] = down;
}

// 帧首清边沿，然后才收消息
Input::BeginFrame();          // 清 pressed/released/wheel/delta
if (!m_window.Poll()) break;  // 回调往里写边沿
Input::SetMouseState(pos, delta, wheel);
```

同时删掉了"回调写一遍、Pull 再写一遍"的双真相（P2-7）：鼠标位置/增量/滚轮只由
`SetMouseState` 一次性快照。

**验证**：`--smoke` 不再依赖键盘；UI 交互走 ImGui 自己的输入栈；
`F11` 隐藏编辑器、`F12` 截图等热键现在能真正触发（见 `Engine::MainLoop`）。
