## §1 启动：`WinMain/main → Engine::Init`

### 1.1 入口层

```
WinMain → main(argc, argv)                runtime/main.cpp（GUI 子系统；控制台构建走 main）
├── DPI 感知
└── Engine::Run(argc, argv)               runtime/Engine.cpp
    ├── --dev：挂接/新建控制台（发布版没有控制台）
    ├── --log / --nolog：日志文件开关
    ├── Engine::Init()
    ├── Engine::MainLoop()
    └── Engine::Shutdown()
```

`Engine::Run` 不含游戏逻辑，只负责上面三段。

### 1.2 初始化顺序（自上而下，失败即返回）

| 顺序 | 调用 | 产出 |
|---|---|---|
| 1 | `Log::Init` / `Timer::Init` / `JobSystem::Init` | 日志、计时、线程池 |
| 2 | `Window::Create` | Win32 窗口 + 消息回调 |
| 3 | `Device::Init` | D3D11 设备、交换链、后备缓冲 |
| 4 | `AudioSystem::Init` | XAudio2 主混音声部 |
| 5 | `Renderer::Init` | 着色器、常量缓冲、实例缓冲、GPU 剔除资源、计时查询 |
| 6 | `AssetManager::Init` | 内置网格/贴图 + `RegisterLevels()` |
| 7 | `World::Init` | `RegisterAllComponents()`（反射工厂，[L14]） |
| 8 | 关卡构建 | 见 §1.3 |
| 9 | `ImGuiLayer::Init` / `Editor::Init` | 编辑器 UI 与 Dock 布局 |
| 10 | 回调注册 | `SetLevelLoader` / `SetSceneLoadedCallback` |

对应调用树：

```
Engine::Init
├── Log::Init → Timer::Init → JobSystem::Init
├── Window::Create → WndProcStatic ⇒ Window::HandleMessage
├── Device::Init → D3D11CreateDevice / CreateSwapChain
├── AudioSystem::Init → XAudio2Create / CreateMasteringVoice
├── Renderer::Init
│   ├── CreateShaders（D3DCompile 每个 .hlsl，[L04]）
│   ├── CreateConstantBuffers / CreateInstanceBuffer
│   ├── CreateGpuCullResources（[L22]）
│   └── CreateTimingQueries（[L17]）
├── AssetManager::Init → RegisterLevels（assets/levels/levels.json）
├── World::Init → RegisterAllComponents
├── Build*Level（§1.3）
├── ImGuiLayer::Init → Editor::Init
└── Editor::SetLevelLoader / SetSceneLoadedCallback
```

### 1.3 关卡构建

```
Engine::Init（或 Engine::LoadLevel）
└── 按 kind 分派
    ├── survivors3d → BuildSurvivors3DLevel       game/Survivors3D.cpp    [L24]
    ├── survivors   → BuildSurvivorsLevel         game/Survivors.cpp      [L23]
    ├── arena       → game::BuildWaveArena        game/WaveArena.cpp      [L17]
    ├── thirdperson → game::BuildThirdPersonLevel game/ThirdPersonLevel.cpp [L03]
    ├── skinning    → game::BuildSkinningLevel    game/SkinningDemo.cpp   [L08]
    └── cull        → game::BuildCullTestLevel    game/CullTestLevel.cpp  [L22]
```

编辑器里切关卡走同一条：

```
Editor::DrawMenuBar → 「关卡」菜单 → m_levelLoader(id) ⇒ Engine::LoadLevel
└── World::Clear → Build*Level → World::SetLevelKind(kind)
```

## §2 一帧：`Engine::MainLoop`

### 2.1 帧循环

```cpp
while (m_running) {
    Input::BeginFrame();
    if (!m_window.Poll()) break;
    Input::SetMouseState(...);
    Timer::Tick();
    AudioSystem::Get().Update(dt);
    if (resized) { Device::Resize; Renderer::SetWindowSize; ... }
    UpdateGameplay(dt);                 // §2.2
    if (m_showEditor) { 编辑器：ImGui + Editor::Draw + RenderViewportScene }
    else              { 无头：BuildRenderScene + Renderer::Render }
    ++m_frameIndex;                     // 截图 / 退出
    Device::EndFrame(vsync);            // Present
}
```

一句话：**输入 → 计时 → 音频 → 玩法 → 渲染 → Present**。

### 2.2 玩法更新：固定步长

```
Engine::UpdateGameplay(dt)
├── 固定步长累加器（[L01]）
│   └── while (acc >= h && steps < kMaxSubSteps)
│       ├── World::FixedUpdate(h)
│       │   ├── PhysicsWorld::Step(World&, h)      physics/PhysicsWorldSim.cpp [L10]
│       │   └── GameObject::FixedUpdate ⇒ Component::OnFixedUpdate
│       └── acc -= h
├── World::Update(dt)
│   └── GameObject::Update(dt)
│       ├── Start（首次）⇒ Component::OnStart
│       └── ⇒ Component::OnUpdate（业务逻辑都在这）
└── 玩法导演（每帧）
    ├── WaveGame::Update / SurvivorsDirector::Update / Survivors3DDirector::Update
    └── 读输入、刷波次、判胜负
```

### 2.3 组件 `OnUpdate` 一览

| 组件 | 文件 | 一句话职责 |
|---|---|---|
| `ThirdPersonController` | `game/ThirdPersonController.cpp` | WASD 移动 + 相机跟随 |
| `SurvivorsPlayerComponent` | `game/Survivors.cpp` | 移动、索敌、发射 |
| `SurvivorsEnemyComponent` | `game/Survivors.cpp` | 追击、接触伤害、掉落 |
| `SurvivorsProjectileComponent` | `game/Survivors.cpp` | 位移、命中、销毁 |
| `SurvivorsGemComponent` | `game/Survivors.cpp` | 吸附、拾取、加经验 |
| `Survivors3D*` | `game/Survivors3D.cpp` | 同上（XZ 平面 + 3D 模型） |
| `EnemyComponent` | `game/WaveGame.cpp` | 行为树驱动（[L17]） |
| `ParticleEmitterComponent` | `game/ParticleEmitter.cpp` | 发射/积分/回收（[L12]） |
| `SkinnedCharacter` | `game/SkinnedCharacter.cpp` | 采样动画、写骨骼调色板（[L08]） |

## §3 渲染：两条入口，一条管线

### 3.1 编辑器入口

```
Editor::Draw
├── DrawMenuBar / DrawToolbar / DrawOutliner / DrawInspector / DrawAssets / …
└── DrawViewport(..., renderCallback)
    └── renderCallback(camera, w, h)        ← std::function
        ⇒ Engine::RenderViewportScene
            ├── World::BuildRenderScene（收集 items / sprites / 灯光）
            ├── game::CollectSkinnedDraws / CollectParticles
            └── Renderer::RenderToViewport → RenderInternal（§3.3）
```

### 3.2 无头入口

```
Engine::MainLoop（--noeditor）
├── World::BuildRenderScene
├── CollectSkinnedDraws / CollectParticles
├── （2D）Camera2D 跟随 → scene.is2D = true
└── Renderer::Render → RenderInternal → CopyPass 到后备缓冲
```

截图：`Engine::CaptureScreenshot → SaveBackbufferToPng`（WIC）。

### 3.3 Pass 顺序与职责（算法只留一句）

```
Renderer::RenderInternal
├── BuildBatches（分批 / 视锥剔除，[L04]）
├── ShadowPass      阴影贴图（[L06]）
├── SkyPass         天空
├── OpaquePass      不透明
│   ├── DrawBatches（CPU 批次）
│   ├── GpuCulledDraw（compute 剔除 + 间接绘制，[L22]）
│   └── SkinnedPass（蒙皮，[L08]）
├── ParticlePass    billboard + 混合（[L12]）
├── DebugPass       线框/法线/包围盒
└── PostPass        ACES + gamma（[L07]）
```

| Pass | 一句话 |
|---|---|
| Shadow | 光源视角渲深度，PCF 软化（细节 L06） |
| Sky | 全屏三角形画天空 |
| Opaque | 实例化绘制 + PBR 着色（L05） |
| GpuCulledDraw | GPU 剔除后按间接参数画 |
| Skinned | 骨骼调色板 + LBS（L08） |
| Particle | 按贴图分组，加法混合 |
| Post | HDR → 色调映射 → 输出 |

## §8 速查表：我想改 X，从哪进？

| 想做的事 | 入口 | 关键链 |
|---|---|---|
| 改主循环 | `Engine::MainLoop` | Timer → UpdateGameplay → Render → Present |

| 加音效 | `PlaySfx("name")` | `AudioSystem::Play` |
| 加 AI 命令 | `Engine::ExecuteAgentCommand` | 新 `cmd` 分支 + JSON 结果 |
| 打游戏包 | `Packager::PackageGameWindows` | exe + assets + game.cfg |

## §9 怎么自己追

1. `ErMao.exe --frames 1 --noeditor`：先看清初始化顺序；
2. 断点：`main` → `Engine::Run` → `MainLoop` → `Editor::DrawViewport` → `RenderInternal` → `World::Update`；
3. 回调在栈里显示为 `lambda`（`RenderViewportScene`）；
4. 虚函数断点会命中所有组件，看 `this` 的实际类型；
5. `JobSystem` 的 worker 线程不在主线程栈里，要切线程窗口；
6. GPU 剔除的可见数有 30 帧 readback 延迟，日志才是准的（L22）。
