# 从入口函数到全部功能：调用栈地图

> 目的：拿到这个仓库后，能从 `main` 出发，顺着函数调用把「一帧里发生了什么」全部追出来。
> 记法：`A → B` 直接调用；`A ⇒ B` 回调/虚函数/函数对象；`★` 业务入口；`…` 省略的中间层。
> 所有函数名都可以在仓库里搜到；路径相对 `engine/src/`。

---

```
    │   ├── AssetManager::Init        → 内置网格/贴图 + RegisterLevels
    │   ├── World::Init               → RegisterAllComponents（反射工厂）
    │   ├── Build*Level               → 关卡对象 + 组件
```

## 1. 入口层：`main` → `Engine::Run`


## 3. 每帧：`Engine::MainLoop`

```cpp
while (m_running) {
    Input::BeginFrame();                       // 清边沿状态
    if (!m_window.Poll()) break;               // 收 Windows 消息
    Input::SetMouseState(...);                 // 鼠标位置/增量/滚轮
    Timer::Tick();                             // 计算 dt
    AudioSystem::Get().Update(dt);             // 回收播放完的 voice
    if (resized) { Device::Resize; Renderer::SetWindowSize; ... }
    UpdateGameplay(dt);                        // 玩法（见 §3.1）
    if (m_showEditor) {                        // 编辑器路径（见 §4.1）
        ImGui::BeginFrame
        Editor::Draw(...)
        ImGui::EndFrame
    } else {                                   // 无头路径（见 §4.2）
        World::BuildRenderScene
        Renderer::Render(...)
        （可选）Survivors/WaveGame DrawUI
    }
    ++m_frameIndex;                            // 截图/退出
    Device::EndFrame(vsync);                   // Present
}
```

### 3.1 玩法更新：固定步长 + 可变渲染

```
Engine::UpdateGameplay(dt)
├── 读取 Editor::IsPlaying()（无编辑器时看 --play）
├── 固定步长累加器
│   └── while (accumulator >= h && steps < kMaxSubSteps)
│       ├── World::FixedUpdate(h)                 scene/World.cpp
│       │   ├── PhysicsWorld::Step(World&, h)     physics/PhysicsWorldSim.cpp
│       │   │   ├── 遍历 Rigidbody/BoxCollider
│       │   │   ├── 重力 → 速度 → 位置
│       │   │   └── 碰撞检测/分离
│       │   └── GameObject::FixedUpdate(h) ⇒ Component::OnFixedUpdate(h)
│       └── accumulator -= h
├── World::Update(dt)                             scene/World.cpp
│   └── 每个根节点 GameObject::Update(dt)
│       ├── GameObject::Start()（首次）⇒ Component::OnStart()
│       └── Component::OnUpdate(dt)               ← 虚函数，业务逻辑都在这
└── 玩法导演（每帧，不受固定步长影响）
    ├── WaveGame::Update(World&, dt, input)        game/WaveGame.cpp
    ├── SurvivorsDirector::Update(World&, dt)      game/Survivors.cpp
    └── Survivors3DDirector::Update(World&, dt)    game/Survivors3D.cpp
```

| 组件 | 文件 | 每帧做什么 |

| `SurvivorsEnemyComponent` | `game/Survivors.cpp` | 追玩家、接触伤害、死亡掉宝石 |
| `SurvivorsProjectileComponent` | `game/Survivors.cpp` | 位移、命中检测、销毁 |

| `Survivors3D*` | `game/Survivors3D.cpp` | 同上，XZ 平面 + 3D 模型 |

## 4. 渲染：两种入口，同一条管线

### 4.1 编辑器路径

```
Editor::Draw(...)                                   editor/EditorUI.cpp
├── DrawMenuBar（文件/关卡/编辑/显示/帮助/模式）
├── DrawToolbar（运行/暂停/Gizmo/保存/加载）
├── DrawOutliner → DrawOutlinerNode
├── DrawInspector → DrawComponents → DrawField（反射驱动）
├── DrawAssets（资源浏览器：导入/缩略图/双击）
├── DrawConsole / DrawStats / DrawSettings / DrawStatusBar
└── DrawViewport(world, renderer, camera, min, size, renderCallback)
    └── renderCallback(camera, width, height)        ← std::function 回调
        ⇒ Engine::RenderViewportScene(camera, w, h)
            ├── World::BuildRenderScene(m_scene, viewCamera)   scene/World.cpp
            │   ├── scene.items.clear / sprites.clear
            │   ├── 遍历 GameObject
            │   │   ├── MeshRenderer → item.mesh/material/world
            │   │   └── SpriteRenderer → SpriteDraw（按 layer 排序）
            │   └── Camera 同步 / 灯光 / 环境光
            ├── game::CollectSkinnedDraws(world, scene)       game/SkinningDemo.cpp
            ├── CollectParticles(world, scene)                game/ParticleEmitter.cpp
            └── Renderer::RenderToViewport(camera, scene, time, w, h, target)
                ├── RenderInternal(...)                       renderer/Renderer.cpp
                │   ├── EnsureViewportTarget
                │   ├── UpdateGpuTiming(begin)
                │   ├── BuildBatches(camera, scene, cull)
                │   ├── ShadowPass(ctx)
                │   ├── SkyPass(ctx)
                │   ├── OpaquePass(ctx, wireframe)
                │   │   ├── DrawBatches(ctx)          ← CPU 批次（或）
                │   │   ├── GpuCulledDraw(ctx)        ← compute 剔除 + 间接绘制
                │   │   └── SkinnedPass(ctx)          ← 蒙皮网格
                │   ├── ParticlePass(ctx)
                │   ├── DebugPass(ctx)
                │   ├── PostPass(ctx, target, w, h)   ← ACES + gamma
                │   └── UpdateGpuTiming(end)
                └── CopyPass(ctx, target, w, h)       ← 视口 RT → 目标
```

### 4.3 单个 Pass 的调用栈

| Pass | 栈 |
|---|---|
| Shadow | `ShadowPass → SetupShadowView(光源相机) → DrawBatches(深度) → PCF 采样在 PBR.hlsl` |
| Sky | `SkyPass → 全屏三角形 → Sky.hlsl` |
| Opaque | `OpaquePass → BuildBatches/UploadInstances → DrawBatches 或 GpuCulledDraw → PBR.hlsl` |
| GPU 剔除 | `GpuCulledDraw → 上传实例 SRV → Dispatch(Cull.hlsl, groups) → CopySubresourceRegion(压缩列表→VB) → DrawIndexedInstancedIndirect` |
| Skinned | `SkinnedPass → 骨骼调色板 CB(b2) → Skinned.hlsl` |
| Particles | `ParticlePass → 按贴图分组 → Particle.hlsl（加法混合）` |
| Debug | `DebugPass → DebugLine.hlsl（线框/法线/包围盒）` |
| Post | `PostPass → Post.hlsl（ACES + gamma + 暗角）` |
| Copy | `CopyPass → Copy.hlsl（全屏三角形）` |

## 14. 怎么自己追调用栈

1. **先跑最小帧**：`ErMao.exe --frames 1 --noeditor`，日志里能看到初始化顺序；
2. **断点**：在 `main`、`Engine::Run`、`Engine::MainLoop`、`Editor::DrawViewport`、`Renderer::RenderInternal`、`World::Update` 各下一个，F10/F11 走一遍；
3. **看回调**：`RenderViewportScene` 是 `std::function`，调用栈里显示为 `lambda`，不是直接函数名；
4. **看虚函数**：`Component::OnUpdate` 断点会命中所有组件，看 `this` 的类型（VS 的 Call Stack 会显示具体类）；
5. **看 GPU**：`GpuCulledDraw` 里 dispatch 之后要等 readback（30 帧延迟），日志里的「GPU可见」才是有效值；
6. **看线程**：`JobSystem` 的 worker 线程不会出现在主线程栈里，需要切线程窗口。
