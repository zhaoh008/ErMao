# P1 · 为什么要自己写一个游戏引擎

> 看完 GAMES104 不等于学会——把 22 讲变成能跑、能改、能打包的代码，才算真的学过。

## 细纲

### 1. 动机：只看不写，等于没学
- 课程知识点 vs 工程实现的距离
- 给自己定三条验收：能跑、能讲、能改

### 2. 目标与非目标
- 教学优先：每个模块对应一讲
- 明确不做：3A 画质、可视化编程、资产创作

### 3. 成果一览
- 编辑器、2D/3D 幸存者、Vulkan 三角形
- 用截图和 30 秒 Demo 建立预期

### 4. 技术选型
- C++17 / D3D11 / Dear ImGui / CMake
- 为什么先 D3D11、Vulkan 放最后

### 5. 系列阅读路线
- 按「骨架 → 渲染 → 动画物理 → 工具 → 游戏 → 进阶」组织
- 每篇一个可运行实验
