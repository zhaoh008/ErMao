## 1. 渲染方程的困难

```
L_o = ∫_Ω f_r · L_i · (N·ω) dω
```

直接光只对"光源方向"积分（第 5 讲），但 `L_i` 还有来自环境反射的部分——这就是间接光。

```
   渲染方程：L_o = ∫ f_r · L_i · (N·ω) dω
                     │
                     ├─ 直接光：L_i 来自光源（第 5 讲）
                     └─ 间接光：L_i 来自其他表面的反射
                                 │
                                 ▼
   近似：常数 → 半球 → SH 探针 → Irradiance Volume → SSAO/SSGI → Lumen
         (本工程)       (9 系数)      (3D 网格)        (屏幕空间)
```
解它需要整个场景的辐射度分布，计算量是 O(场景)。

## 2. 近似层级（从便宜到贵）

| 方法 | 一句话 | 成本 |
|---|---|---|
| 常数环境光 | `ambient * albedo` | 0 |
| 半球环境光 | 按法线朝上/朝下插值 | 0（本工程） |
| 光照探针 + SH | 在空间采样点存 9 个球谐系数 | 低 |
| Irradiance Volume | 3D 网格探针，插值 | 中 |
| SSAO / SSGI | 屏幕空间射线 | 中高 |
| Lumen / DDGI | 动态探针 + 光线追踪 | 高 |

## 3. 球谐（SH）的数学

把环境光写成球面函数 `L(ω)`，用前 9 个球谐基 `Y_lm(ω)` 展开：

```
L(ω) ≈ Σ_{l=0..2, m} c_lm · Y_lm(ω)
```

- `l=0`：常数项（平均亮度）；
- `l=1`：3 个一阶项（方向性，等价于"主光方向"）；
- `l=2`：5 个二阶项（更细的方向变化）。

漫反射只需要"余弦卷积后的辐照度"，而余弦核在 SH 空间是对角的，
所以可以用**同一组系数**直接算：

```
E(N) ≈ Σ_l A_l · Σ_m c_lm Y_lm(N)
```

`A_0 = π`, `A_1 = 2π/3`, `A_2 = π/4` 是余弦卷积的特征值（Ramamoorthi & Hanrahan 2001）。

**为什么是 9 个**：99% 的漫反射能量集中在前三阶（l ≤ 2），9 个系数足够。

## 4. 本工程的现状

```cpp
float hemi = N.y * 0.5 + 0.5;
float3 ambient = lerp(ambientDown, ambientUp, hemi) * ambientIntensity;
```

- 这是 SH 的 `l=0` + 一个简化的 `l=1`（只有 Y 方向）；
- 没有空间变化（所有物体同一环境光）；
- 没有遮蔽（SSAO 缺失）→ 角落不会变暗，物体"浮"在环境里。
