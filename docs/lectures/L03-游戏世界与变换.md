## 1. 变换的数学

### 1.1 局部变换 = T · R · S

一个 `Transform` 有平移 `t`、旋转 `q`、缩放 `s`。写成 4×4 矩阵（列向量约定，`p' = M p`）：

```
M_local = T(t) · R(q) · S(s)
```

顺序不能换：先缩放、再旋转、最后平移。

- 若先平移再旋转，物体会绕**世界原点**转，而不是绕自己转；
- 矩阵乘法不交换，`T·R ≠ R·T`，这是变换顺序必须写死的根本原因。

代码里 `BoneTransform::ToMatrix()` 就是这一行：

```cpp
return Mat4::Translation(translation) * QuatToMatrix(rotation) * Mat4::Scale(scale);
```

### 1.2 层级：世界矩阵 = 父世界矩阵 · 局部矩阵

```
M_world(child) = M_world(parent) · M_local(child)
```

递归到根即可。本工程的 `GameObject::WorldMatrix()` 带缓存（`m_worldMatrix`），
父节点变换变化时递归失效（`m_dirty`）。

**复杂度**：朴素实现每帧对每个节点从根重算，O(n·depth)；缓存 + 脏标记后，
只有变化的子树会重算，均摊接近 O(变化的节点数)。

### 1.3 逆变换

`M^{-1}` 用于"把世界坐标变回局部坐标"（例如把鼠标射线变换到模型空间做拾取）。
对 T·R·S 这种仿射矩阵，可以解析求逆：

```
M^{-1} = S^{-1} · R^{-1} · T^{-1} = S^{-1} · R^T · T(-t)
```

因为旋转矩阵正交，`R^{-1} = R^T`——这比通用 4×4 求逆快且数值稳定。
`Mat4::Inverse()` 走的是通用高斯消元，教学够用；工业引擎会特判仿射矩阵走解析式。

## 2. 四元数

### 2.1 定义与旋转公式

单位四元数 `q = (x, y, z, w) = (sin(θ/2)·a, cos(θ/2))`，`a` 是单位轴。

对向量 `v`（看作纯四元数 `(v, 0)`）的旋转：

```
v' = q · v · q*          （q* 是共轭，单位四元数下等于逆）
```

展开成矩阵就是 `R(q)`：

```
        | 1-2(y²+z²)   2(xy - zw)   2(xz + yw) |
R(q) =  | 2(xy + zw)   1-2(x²+z²)   2(yz - xw) |
        | 2(xz - yw)   2(yz + xw)   1-2(x²+y²) |
```

**为什么用四元数**：

| 表示 | 存储 | 插值 | 万向锁 | 复合 |
|---|---|---|---|---|
| 欧拉角 | 3 float | 不能直接插（角度环绕） | 有（pitch=±90° 丢一维） | 需转矩阵 |
| 旋转矩阵 | 9 float | 不能直接插（会破坏正交性） | 无 | 矩阵乘 |
| 四元数 | 4 float | Slerp（球面最短路径） | 无 | 四元数乘 |

### 2.2 复合

先转 `q1` 再转 `q2`，总旋转是 `q2 · q1`（注意顺序，和矩阵一致）。

### 2.3 Slerp 的推导

两个单位四元数夹角 `Ω`，`cos Ω = q0 · q1`。球面线性插值：

```
slerp(q0, q1, t) = ( sin((1-t)Ω)·q0 + sin(tΩ)·q1 ) / sin Ω
```

- 当 `Ω → 0` 时除以 `sinΩ` 不稳定，要退化成线性插值再归一化（本工程 `Quat::Slerp` 在 `dot > 0.9995` 时走 lerp）；
- 若 `q0·q1 < 0`，说明两四元数在 4D 球面上是"对跖"的（同一个旋转的两种表示），
  要先取反 `q1 = -q1`，否则会走远路，表现为"转了一大圈"。

```cpp
static Quat Slerp(const Quat& a, const Quat& b, float t) {
    float d = Dot(a, b);
    Quat bb = b;
    if (d < 0) { bb = -b; d = -d; }      // 最短路径
    if (d > 0.9995f) return Lerp(a, bb, t).Normalized();
    float theta = std::acos(d);
    ...
}
```

### 2.4 欧拉角 → 四元数

本工程用 UE 风格 YXZ：`yaw`(Y) → `pitch`(X) → `roll`(Z)：

```
q = q_yaw · q_pitch · q_roll
```

顺序不同结果不同；欧拉角只用来做**输入/显示**，内部一律四元数（第 8 讲骨骼、第 15 讲角色朝向都是）。

## 3. 代码

### 3.1 世界矩阵缓存

```cpp
const Mat4& GameObject::WorldMatrix() const {
    if (m_dirty) {
        m_worldMatrix = Parent() ? Parent()->WorldMatrix() * LocalMatrix() : LocalMatrix();
        m_dirty = false;
    }
    return m_worldMatrix;
}
```

`mutable` + `const`：逻辑上"查世界矩阵"不改变对象，但缓存会变。

### 3.2 反射与序列化

每个组件的字段用 `Field(...)` 注册：

```cpp
t.Field("albedo", FieldType::Color, &MeshRenderer::albedo, "基础色");
```

同一份描述同时驱动：

- 检视器 UI（按 `FieldType` 生成控件）；
- JSON 读写（`World::ToJson/FromJson`）；
- 因此"能改的字段"和"能存的字段"永远一致，不会出现 UI 有、存档没有。

### 3.3 场景往返自检

```bat
build\bin\ErMao.exe --test-serialize --frames 2
:: [自检] 序列化往返: 17 -> 17 个对象，再次往返稳定=是，首次字节一致=是
```

注意后面的"稳定=是"：**第一次**往返可能因四元数归一化差 1 ULP，
所以自检断言的是"再往返一次完全一致"（幂等），比"单次相等"更强。

## 5. 常见错误

| 错误 | 现象 | 修正 |
|---|---|---|
| 先平移后旋转 | 物体绕世界原点公转 | T·R·S |
| 四元数不归一化 | 缩放随旋转变化（矩阵含非正交分量） | 构造/插值后归一化 |
| Slerp 不处理负点积 | 偶尔"转一大圈" | 负则取反 |
| 欧拉角直接插值 | 角度 359°→1° 时反向 | 转四元数插值 |
| 每帧对全场景重算世界矩阵 | 大场景 CPU 爆 | 脏标记缓存 |

## 练习（故意改坏）

1. 把 `Mat4::Translation * R * S` 改成 `R * S * T`：**预期**物体绕世界原点公转。
2. 把 `Quat::Slerp` 里的 `if (d < 0) bb = -b` 删掉：**预期**某些角度过渡时"转一大圈"。
3. 把 `WorldMatrix()` 的缓存去掉（每次从根重算）：**预期**画面不变，但统计面板 CPU 时间上升。
