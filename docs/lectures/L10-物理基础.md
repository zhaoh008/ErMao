## 1. 积分器：为什么用半隐式欧拉

给定位置 `x`、速度 `v`、加速度 `a`，三种常见积分：

| 方法 | 更新顺序 | 稳定性 | 说明 |
|---|---|---|---|
| 显式欧拉 | `x += v·h; v += a·h` | 差（能量增长） | 弹簧会越弹越高 |
| 半隐式欧拉（symplectic） | `v += a·h; x += v·h` | 好 | 先更新速度再用新速度更新位置 |
| Verlet | 用前两帧位置 | 好 | 分子动力学常用 |

本工程：

```
   每步 h：
     v ← v + a·h        （先更新速度：半隐式）
     x ← x + v·h        （再用新速度更新位置）
     碰撞：位置修正 + 法向反弹 + 切向阻尼
     休眠：速度小且落地 → sleepTimer += h → 超过阈值停止模拟
```

```cpp
if (body->useGravity) body->velocity.y += m_gravity * dt;   // 先速度
pos += body->velocity * dt;                                 // 再位置
```

**为什么半隐式更稳**：对弹簧振子 `a = -ω²x`，半隐式欧拉的放大矩阵行列式为 1（保面积），
能量在长时间内不发散；显式欧拉每步放大 `1 + ω²h² > 1`，能量指数增长。
严格推导：把两种方法写成矩阵形式，比较特征值模长即可；半隐式要求 `ωh < 2`，显式要求 `ωh < 1` 且仍然耗散/增长。

## 2. 重力与落地

重力加速度 `g = -9.8 m/s²`（本工程用 -22，游戏手感更"脆"）。

自由落体解析解：

```
v(t) = v0 + g·t
x(t) = x0 + v0·t + ½g·t²
```

半隐式欧拉每步的离散解与解析解的误差是 O(h)（一阶），h=1/60 时落地时间误差约 1~2 帧——
对游戏足够，对航天不够。

### 2.1 落地检测

```cpp
if (pos.y - halfHeight < 0.0f) {          // 与地面（y=0）相交
    pos.y = halfHeight;                    // 位置修正
    if (body->velocity.y < 0.0f) {
        body->velocity.y = -body->velocity.y * body->restitution;   // 反弹
        if (std::fabs(body->velocity.y) < 0.35f) body->velocity.y = 0;  // 抖动消除
    }
}
```

- `restitution = 0`：完全非弹性（落地即停）；
- `restitution = 1`：完全弹性（能量不损失）；
- 小速度截断（0.35）是"睡眠阈值"：否则球会在 1cm 高度上永远弹。

## 3. 冲量法：碰撞响应的一般形式

两个物体沿法线 `n` 碰撞，相对速度 `v_rel = v_b - v_a`，法向分量 `v_n = v_rel · n`。
恢复系数 `e` 定义"分离速度 = -e × 接近速度"：

```
v_n' = -e · v_n
```

需要的冲量 `j`（标量）由动量守恒推出：

```
j = -(1 + e) · v_n / (1/m_a + 1/m_b)
v_a -= j · n / m_a
v_b += j · n / m_b
```

若 `b` 是静态物体（`m_b = ∞`），分母只剩 `1/m_a`。

**摩擦**（库仑模型）：切向冲量 `j_t` 受法向冲量限制：

```
|j_t| ≤ μ · |j_n|
```

本工程是简化版：落地时直接对水平速度乘一个阻尼系数

```cpp
const float damping = max(0.0f, 1.0f - friction * 6.0f * dt);
velocity.x *= damping; velocity.z *= damping;
```

优缺点：
- 优点：稳定、不会抖、参数直观；
- 缺点：不是真冲量，斜坡上的滑动/静摩擦不精确（第 11 讲会讲为什么）。

## 4. 休眠（sleeping）

静止的物体继续积分是浪费。判定：

```cpp
if (grounded && speed² < threshold) sleepTimer += h;
if (sleepTimer > 0.6s) { velocity = 0; sleeping = true; }
```

- 被撞/被推时唤醒（`sleepTimer = 0`）；
- 统计面板"物理: 动态/静态/休眠"对应这个状态。

**为什么需要**：1000 个箱子的场景，不休眠每帧要跑 1000 次积分 + 碰撞，
休眠后只剩"被唤醒的"几个，CPU 时间可以降一个数量级。

## 5. 本工程物理的边界（诚实清单）

| 项 | 现状 |
|---|---|
| 形状 | 球 + 轴对齐盒（AABB） |

## 练习（故意改坏）

1. 把半隐式欧拉改成显式（先 `x += v*h` 再 `v += a*h`）：**预期**弹跳越来越高（能量增长），或下落变慢。
2. 把 `restitution` 改成 1.2：**预期**球越弹越高（违反能量守恒）。
3. 把休眠阈值删掉：**预期**静止物体仍在积分，统计面板"休眠"恒为 0，CPU 时间上升。
