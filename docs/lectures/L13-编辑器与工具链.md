## 1. 即时模式 UI 的本质

保留模式（Win32/Qt）：控件是对象，改状态 → 重绘。
即时模式（ImGui）：**每帧重新声明整棵 UI**，状态存在你自己的变量里：

```cpp
if (ImGui::Button("运行")) EnterPlayMode(world);
ImGui::SliderFloat("粗糙度", &material.roughness, 0.04f, 1.0f);
```

代价：每帧重建（几万个顶点，可忽略）。
收益：**没有 UI 与数据的同步问题**——UI 直接读写你的变量，不可能出现"控件显示旧值"。

### 1.1 Dock 布局

`ImGui::DockBuilderSplitNode` 按比例切分：左 20%、右 26%、下 26%，再把面板 `DockWindow` 进去。
布局存 `imgui.ini`。

**一个真实的坑（审核 P2-22）**：`--frames/--screenshot` 自动截图会读 `imgui.ini`，
如果上次把视口面板拖到 0 尺寸，自动截图就是空的。修正：自检运行禁用 ini 并强制默认布局。

## 2. 离屏视口

编辑器不直接画窗口，而是：

```
  场景 ──▶ Renderer::RenderToViewport ──▶ RGBA8 RT（宽高 = 面板尺寸）
                                              │
                                              ▼
                              ImGui::Image(RT.SRV)  ──▶ 视口面板
```

```
场景 → 渲染到 RGBA8 RT → ImGui::Image(RT 的 SRV) → 视口面板
```

- RT 尺寸 = 面板尺寸，每帧检查尺寸变化并重建；
- 相机 `aspect = RT 宽 / RT 高`，所以拖面板不变形；
- 优点：视口可以被遮挡、可以多开（将来做第二视口只是多一个 RT）。

## 3. 拾取：屏幕坐标 → 世界射线

### 3.1 反投影

鼠标在视口内的像素坐标 `(x, y)`，视口尺寸 `(w, h)`：

```
ndc.x =  2x/w - 1
ndc.y =  1 - 2y/h        // 注意 Y 翻转
ndc.z =  0（近平面） 或 1（远平面）
```

用 `invViewProj` 把 `(ndc, 0)` 和 `(ndc, 1)` 变回世界空间，得到两个点：

```
p_near = invViewProj · (ndc.x, ndc.y, 0, 1)   （再除以 w）
p_far  = invViewProj · (ndc.x, ndc.y, 1, 1)
ray.origin = p_near
ray.dir    = normalize(p_far - p_near)
```

代码：`Camera::ScreenPointToRay`（`renderer/Camera.cpp`）。

### 3.2 射线 vs AABB（slab 法）

对每一维求射线进入/离开该维 slab 的参数区间：

```
t1 = (min.x - o.x) / d.x
t2 = (max.x - o.x) / d.x
tmin = max(tmin, min(t1,t2))
tmax = min(tmax, max(t1,t2))
```

三维都做，若 `tmin <= tmax` 且 `tmax >= 0` 则命中，`tmin` 是入射距离。
除法要处理 `d ≈ 0`（平行于 slab）：用 `1/d = ±∞` 的 IEEE 语义可以自然处理，或特判。

代码：`World::Raycast` → 对每个物体的世界 AABB 做 slab 测试，取最近命中。

## 4. Gizmo（平移手柄）

选中物体后画三个轴。**难点是"鼠标拖拽 → 世界位移"的换算**，本工程用屏幕空间投影：

1. 把物体原点 `O` 和轴端点 `O + axis·L` 投影到屏幕，得到 `o`、`e`；
2. 轴在屏幕上的方向 `dir = normalize(e - o)`，像素长度 `len = |e - o|`；
3. 拖拽时鼠标位移在 `dir` 上的投影 `Δpx = (mouse - start) · dir`；
4. 世界位移 = `Δpx · (L / len)`（世界长度 / 像素长度）。

这等价于"沿轴的 1D 参数化"，不需要求射线与直线的最短距离，稳定且够用。

**F 聚焦**：用物体 AABB 求中心 `C` 与半径 `R`，相机放在 `C - forward · d`，
其中 `d = R / tan(fov/2) · 1.7`（1.7 是留白系数）。

## 5. 资源缩略图

`Renderer::GetMeshThumbnail`：

1. 用网格包围球算相机距离（保证不同尺寸填满画面）；
2. 渲染到 128² RT（复用 PBR 管线，含天空/阴影）；
3. 按 `meshId` 缓存，只渲染一次；
4. 保存/恢复 `m_stats`，否则缩略图会污染统计面板。

这是"编辑器功能复用渲染管线"的典型例子：不需要单独的预览渲染器。
