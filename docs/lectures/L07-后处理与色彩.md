# 第 7 讲：后处理与色彩——HDR、色调映射与 Gamma【进阶】

> 对应 GAMES104 第 7 讲（渲染管线与后处理）。
> 代码：`shaders/Post.hlsl`、`renderer/Renderer.cpp` 的 `PostPass`、`RenderTarget`（RGBA16F）。
> 目标：解释"为什么需要 HDR、为什么要 tone mapping、为什么最后要开方"。

---

## 1. 线性空间与显示空间

光照计算必须在**线性空间**：两盏灯叠加是 `L1 + L2`，不是 `(L1^0.45 + L2^0.45)`。
但显示器接收的是**编码值**（sRGB）：8 位缓冲里存的是 `encode(linear) ≈ linear^(1/2.2)`。

所以管线是：

```
  HDR RT (R16G16B16A16_FLOAT)：光照结果，值可以 > 1
        │  × exposure
        ▼
  ACES 色调映射（有界、保留高光）
        ▼
  gamma 编码（^(1/2.2)）
        ▼
  后备缓冲 RGBA8 → 显示器
```

```
光照(线性 HDR) → 色调映射(线性→[0,1]) → Gamma 编码(→sRGB) → 显示器
```

- 引擎内部：`albedo` 是线性色；贴图是 `_SRGB` 格式，硬件采样时自动转线性（第 5 讲）；
- 场景 RT 用 `R16G16B16A16_FLOAT`（HDR），可以存 >1 的亮度；
- 后处理最后一步做 gamma，输出到 `RGBA8_UNORM` 后备缓冲。

---

## 2. 为什么需要色调映射

太阳亮度可能是 10，灯泡 50，而显示器只能显示 [0,1]。
直接 clamp 会让高光变成一片死白，暗部细节全丢。色调映射函数 `T(x)` 要：

1. `T(0) = 0`，`T(∞) → 1`（有界）；
2. 中间调近似线性（不改变整体明暗关系）；
3. 高光平滑压缩（保留高光细节）。

### 2.1 ACES 近似（Narkowicz 拟合）

```hlsl
float3 ACESFilm(float3 x) {
    return saturate((x * (2.51*x + 0.03)) / (x * (2.43*x + 0.59) + 0.14));
}
```

这是对 ACES RRT+ODT 的有理函数拟合，误差在 1% 内，只需 5 次乘加。
性质：`x→0` 时 `≈ 0.03x/0.14 ≈ 0.214x`（略提亮暗部），`x→∞` 时 `→ 2.51/2.43 ≈ 1.03`（有界）。

### 2.2 曝光

```hlsl
color *= exposure;      // 曝光是乘法，等价于相机光圈/快门
color = ACESFilm(color);
```

曝光在 tone mapping **之前**，所以它影响"进入压缩曲线的位置"，而不是简单调亮度。

## 3. Gamma 编码

线性值 `c` 写到 8 位缓冲时要做：

```
c_encoded = c^(1/2.2)
```

硬件 sRGB 格式会自动做，但我们输出到 `UNORM` 后备缓冲，所以在 shader 里手动：

```hlsl
color = pow(color, 1.0 / 2.2);
```

**常见错误**：对已经是 sRGB 的贴图再做一次 gamma（双重编码），颜色会发灰。
本工程贴图用 `_SRGB` 格式、albedo 用线性色，只有最终输出做一次 gamma。

---

## 4. 全屏三角形

后处理不需要顶点缓冲：用 `SV_VertexID` 生成覆盖全屏的三角形：

```hlsl
float2 uv = float2((vertexId << 1) & 2, vertexId & 2);
o.clip = float4(uv * float2(2, -2) + float2(-1, 1), 1, 1);
ctx->Draw(3, 0);
```

比"两个三角形 + 顶点缓冲"少一次绑定，且没有对角线接缝。

---

## 5. 后处理里的其他东西

本工程目前只有：

- tone mapping + gamma + 暗角（vignette）；
- 调试视图（阴影/法线直接输出）。

**没有** Bloom、景深、运动模糊、SSAO——它们都是"在 HDR 图上再做几遍全屏 pass"，
第 22 讲会讨论什么时候值得加。

Bloom 的数学预告：亮度阈值提取 → 降采样 → 高斯模糊（可分离：2D 高斯 = 水平 1D + 垂直 1D，
复杂度从 O(k²) 降到 O(2k)） → 叠加回原图。

## 7. 练习（故意改坏）

1. 把 `Post.hlsl` 最后的 `pow(color, 1/2.2)` 删掉：**预期**画面整体变暗（线性值直接当 sRGB 显示）。
2. 把曝光从 1.0 改成 4.0：**预期**变亮但高光不糊（ACES 压缩），与"直接乘 4 再 clamp"对比能看出差别。
3. 把场景 RT 从 `R16G16B16A16_FLOAT` 改成 `R8G8B8A8_UNORM`：**预期**太阳/高光处死白，暗部出现色带。
