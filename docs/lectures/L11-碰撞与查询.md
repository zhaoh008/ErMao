## 1. AABB 与 OBB

**AABB**（轴对齐包围盒）：`min/max` 两个点，8 字节/维，求交 O(1)。

- 优点：查询快、可以增量更新；
- 缺点：物体旋转后包围盒变大（"包围盒膨胀"），剔除变松。

本工程全部用 AABB：网格有局部 AABB，物体变换后把 8 个角点变换再取包围盒（`World::GetObjectBounds`）。
旋转 45° 的立方体，AABB 体积会变成 √3 倍——这就是"松包围盒"的代价。

**OBB**（有向包围盒）更紧，但求交需要分离轴定理（SAT），代码复杂度高一个量级。

---

## 2. 射线与 AABB：slab 法

对每一维，求射线进入/离开该维 slab 的参数：

```
   射线 o + d*t 与 AABB [min, max]：
     t1 = (min.x - o.x) / d.x
     t2 = (max.x - o.x) / d.x
     tmin = max(tmin, min(t1, t2))
     tmax = min(tmax, max(t1, t2))
   三个轴都做；tmin <= tmax 且 tmax >= 0 则命中
```

```
t1 = (min.x - o.x) / d.x
t2 = (max.x - o.x) / d.x
tmin = max(tmin, min(t1, t2))
tmax = min(tmax, max(t1, t2))
```

三维都做完后：

- 若 `tmax < max(tmin, 0)` → 不相交；
- 否则 `tmin` 是入射参数，命中点 `o + d·tmin`。

**除零**：`d.x = 0` 时 `1/d.x = ±∞`，IEEE 语义下 `min/max` 仍然正确（只要 `o.x` 不在 slab 内，
`t1 = ±∞` 会把区间清空）。所以可以不做特判，但要注意 `0/0 = NaN`（射线原点正好在边界上）。

代码：`World::Raycast` 对每个物体做 slab 测试，取最小 `t`。

## 3. 射线与球：一元二次方程

```
|o + d·t - c|² = r²
=> (d·d)t² + 2d·(o-c)t + |o-c|² - r² = 0
```

判别式 `Δ = b² - 4ac`，`Δ < 0` 无交点。取较小的正根。

用于：AI 视线检测（第 16 讲）、子弹命中（刷怪 Demo 的投射物用球-球近似）。

---

## 4. 球 vs AABB：最近点

球心 `c`、半径 `r`，盒子 `[min, max]`：

```
closest = clamp(c, min, max)
if |c - closest| < r  → 相交
```

推出方向 `n = normalize(c - closest)`，穿透深度 `d = r - |c - closest|`。

这就是第三人称控制器的水平碰撞（第 15 讲）：只在 XZ 上做，竖直交给射线。

**边界情况**：`c` 在盒子内部时 `|c - closest| = 0`，方向退化。
本工程直接跳过（`distance < 1e-4`），工业实现会选"最小穿透轴"推出。

## 5. 空间划分

射线检测朴素实现是 O(物体数)。本工程物体数 < 100，够用。
工业做法：

| 结构 | 适用 | 构建 | 查询 |
|---|---|---|---|
| 均匀网格 | 均匀分布（地形） | O(n) | O(格子内物体) |
| 四叉/八叉树 | 静态场景 | O(n log n) | O(log n) |
| BVH | 动态场景、GPU | O(n log n) | O(log n)，可并行 |
| 哈希网格 | 稀疏大世界 | O(n) | O(1) 均摊 |

本工程的 AI 导航用**均匀栅格**（第 16 讲）：把 XZ 平面按 0.5m 划格，静态物体的 AABB 投影到格子做标记。

## 7. 练习（故意改坏）

1. 把 ray-AABB 的 `tmax = min(tmax, max(t1,t2))` 改成 `tmax = max(...)`：**预期**射线穿透所有物体。
2. 把球-AABB 的 `distance < 1e-4` 保护删掉：**预期**球心进入盒子内部时被推向 NaN 方向，角色瞬移。
3. 把世界 AABB 的 8 角点变换改成只变换中心点：**预期**旋转物体的包围盒不随旋转变大，剔除会误剔。
