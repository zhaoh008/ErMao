## 哪些内容不用花时间

打包器（Packager）、Linux 源码包、文件对话框、`imgui.ini` 布局、Windows 消息循环细节——
它们是工程配套，不是引擎原理。需要时查 [发布与工程](../版本/发布与工程.md) 即可。

## 这套东西的边界

- 渲染：单线程前向管线 + 可选 GPU 剔除；没有 IBL/延迟渲染/阴影级联；Vulkan 只到阶段一；
- 物理：教学级球/盒碰撞，没有 GJK/EPA、CCD、关节；
- 网络、完整 GI：只有设计文档（L18 / L21）；
- 平台：只有 Windows 二进制，Linux 只给源码包；
- 编辑器：没有撤销栈。

**知道边界，比多背十个公式有用。** 每讲讲义末尾的“差距”会写清还没做什么。
