## 1. 关键帧采样

每根骨骼一条轨道：`(time, TRS)` 的关键帧序列。给定时间 `t`：

1. 找到 `t` 落在哪两个关键帧 `[k_i, k_{i+1}]` 之间；
2. 归一化 `α = (t - k_i.time) / (k_{i+1}.time - k_i.time)`；
3. 平移/缩放线性插值，旋转用四元数 **Slerp**（第 3 讲）。

```
T = lerp(T_i, T_{i+1}, α)
S = lerp(S_i, S_{i+1}, α)
R = slerp(R_i, R_{i+1}, α)
```

**为什么旋转不能 lerp**：四元数 lerp 后模长 < 1，归一化后的角速度不均匀
（在两端慢、中间快），表现为"动作一顿一顿"。Slerp 是等角速度的。

### 1.1 循环

```cpp
if (loop) { t = fmod(t, duration); if (t < 0) t += duration; }
```

`fmod` 的负数处理很容易漏：`t = -0.1` 时 `fmod` 给 `-0.1`，要加 `duration` 变 `0.9·duration`。

## 2. Cross-fade（姿势混合）

两个片段 A、B 同时采样，按权重 `w` 混合：

```
   clipA(t) ──sample──▶ poseA（局部 TRS × N 骨骼）
                                │
                                ├─ BlendPoses(w) ──▶ pose ──▶ world ──▶ skin
                                │
   clipB(t) ──sample──▶ poseB ──┘
```

```
T = lerp(T_A, T_B, w)
S = lerp(S_A, S_B, w)
R = slerp(R_A, R_B, w)
```

**关键点：混合发生在局部 TRS 上，不是最终矩阵上。**

- 对矩阵做 `lerp` 会破坏正交性（出现缩放/剪切），表现为模型"塌陷"；
- 对 TRS 混合再重建矩阵，结果仍然是刚体变换。

```cpp
void BlendPoses(const std::vector<BoneTransform>& a, ..., float alpha, ...) {
    r.translation = Lerp(pa.translation, pb.translation, alpha);
    r.scale       = Lerp(pa.scale, pb.scale, alpha);
    r.rotation    = Quat::Slerp(pa.rotation, pb.rotation, alpha);
}
```

### 2.1 同步问题

如果 A、B 的周期不同（2s vs 3s），直接按各自时间采样，混合时会"互相拉扯"。
工业做法：**同步相位**——把两个片段归一化到同一相位 `φ ∈ [0,1)`，再按 `φ` 分别采样。
本工程的两个片段长度不同但没有同步，所以混合时会看到一点"频率打架"——这是刻意保留的教学点。

## 3. 状态机与过渡

```
Idle --(速度>0.1)--> Walk --(速度>5)--> Run
  ↑                    |                 |
  └----(速度<0.1)------┘<----(速度<5)----┘
```

每个过渡有：

- **条件**（布尔/阈值）；
- **过渡时长**（cross-fade 时间，通常 0.1~0.3s）；
- **过渡曲线**（线性、平滑步、或按"目标动作相位"对齐）。

本工程的刷怪 Demo 用"两个片段常驻混合"代替完整状态机（够用且简单），
真正的状态机在 `docs/教学/讲义/L17-行为树.md` 的行为树里讨论。

## 4. 根运动（Root Motion）

如果动画本身带位移（走路前移），有两种用法：

1. **In-place**：动画原地播放，位移由代码控制（本工程第三人称就是这样）；
2. **Root Motion**：把根骨骼的位移提取出来驱动角色，动画与位移严格一致。

Root Motion 的数学：每帧取根骨骼相对上一帧的位移 `Δp`、旋转 `Δq`，应用到角色 Transform，
再把根骨骼的位移清零（否则会叠加两次）。

---

## 5. 本工程的每帧流程

```cpp
m_timeA += dt * speedA;
m_timeB += dt * speedB;
clipA.Sample(m_timeA + phase, skeleton, m_poseA);
clipB.Sample(m_timeB + phase, skeleton, m_poseB);
BlendPoses(m_poseA, m_poseB, blend, m_pose);
skeleton.ComputeWorld(m_pose, m_worldMatrices);
skeleton.ComputeSkinning(m_worldMatrices, m_bones);
```

- `phase` 让 4 个角色不同步；
- `blend` 是检视器可调字段（0=wave，1=sway）。

## 6. 实验

```bat
build\bin\ErMao.exe --level skinning --play
```

选中角色，拖动 `blend`：

- 0.0：纯 wave（左右倒）；
- 1.0：纯 sway（前后摆）；
- 0.5：两者叠加，能看到"中间姿势"。

把 `speedA` 调到 0，`speedB` 调到 2，观察一个片段静止、一个快速播放的混合结果。
