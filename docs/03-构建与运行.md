# 构建、运行与排错

## 1. 环境要求（本机已验证）

| 项 | 版本 |
|---|---|
| Windows | 10 / 11 x64 |
| Visual Studio | 2022（MSVC v143，需“使用 C++ 的桌面开发”工作负载） |
| Windows SDK | 10.0.19041 以上 |
| CMake | ≥ 3.20（VS 自带亦可；本机用 CLion 的 4.2.2） |
| 显卡 | 支持 D3D11 Feature Level 11_0（无独显时自动回退 WARP 软光栅） |

## 2. 一键构建

```bat
build.bat            :: Release
build.bat Debug      :: Debug（带 D3D11 调试层与断言）
```

脚本会：找 VS → `vcvars64` → CMake 生成 VS 工程 → `msbuild` 编译 Release → 把 `shaders/` 与 `assets/` 拷到 exe 旁边。

产物：`build\bin\ErMao.exe`（自包含，可直接拷走）。

## 3. 运行

```bat
build\bin\ErMao.exe
```

命令行参数：

| 参数 | 作用 |
|---|---|
| `--play` | 启动即进入 Play 模式（游戏相机 + 物理 + AI） |
| `--noeditor` | 不绘制编辑器 UI |
| `--frames N` | 跑 N 帧后自动退出（自动化验证） |
| `--screenshot path.png` | 第 N 帧保存截图后退出 |
| `--debugview 0..5` | 0 正常 / 1 阴影系数 / 2 世界法线 / 3 基础色 / 5 阴影贴图 |
| `--level thirdperson\|demo` | 选择代码关卡 |
| `--smoke` | 脚本化移动/跳跃自检（日志打印玩家坐标） |
| `--import <path>` | 导入 OBJ 自检 |
| `--noshadows` | 关闭阴影（教学对比用） |
| `--debugview N` | 调试视图：0 正常 / 1 阴影 / 2 法线 / 3 基础色 |
| `--roughness R` / `--metallic M` | 覆盖全场景材质（生成对比图） |
| `--level skinning` | 骨骼蒙皮演示关卡 |
| `--test-serialize` | 场景 JSON 往返自检（字节级比较） |

例：

```bat
build\bin\ErMao.exe --play --noeditor --frames 150 --screenshot docs\screenshots\play.png
```

## 4. 常见问题

**Q: 编译报 “找不到 Windows SDK 10.0.xxxxx”**
装 VS 时勾选 Windows SDK，或在 VS Installer 里补装。

**Q: 启动黑屏 / 窗口一闪而过**
看 exe 同目录的 `ErMao.log`。常见原因：
- 着色器路径找不到 → 确认 `shaders/` 被拷到 exe 旁边（build 脚本会自动做）；
- 显卡驱动过旧 → 日志里会打印 “退回 WARP 软光栅”。

**Q: 中文显示成方块**
字体图集用 GDI 光栅化，中文回退到 “Microsoft YaHei”。精简版 Windows 若没有该字体，会回退 Segoe UI（中文变方块）。装一个中文字体即可。

**Q: 运行时崩溃**
先看 `ErMao.log` 最后一行。历史踩坑：
1. 子对象所有权（已在 `World::m_objects` 修复）；
2. 交换链 resize 前没释放 RTV/DSV；
3. 常量缓冲结构体不是 16 字节对齐。

**Q: 编辑器里拖了物体，重启后又变回去了？**
关卡是代码优先的（`game/ThirdPersonLevel.cpp`）。编辑器里的改动要点"保存"才会写到
`assets/scenes/*.ermao.json`，下次启动仍会用代码关卡；需要恢复编辑结果时在"文件 → 打开场景"里加载它。

**Q: 帧率很低**
`F3` 看是不是阴影/后处理；`F1`（或 Stats 面板）看 draw call 与三角形数。
本机 RTX 3090 上 1600×900 约 40–60 FPS（vsync 限制在 60）。

## 5. 代码阅读路线（建议按顺序）

| 顺序 | 文件 | 你会看到 |
|---|---|---|
| 1 | `runtime/main.cpp` → `runtime/Engine.cpp` | 引擎怎么启动、主循环长什么样 |
| 2 | `core/Math.h` | 向量/矩阵/四元数/视锥，全部是手写 |
| 3 | `rhi/Device.cpp` | D3D11 设备与交换链的最小初始化 |
| 4 | `renderer/Renderer.cpp` | 阴影 → 天空 → 不透明 → 调试 → 后处理 |
| 5 | `engine/shaders/PBR.hlsl` | GGX、阴影采样、调试视图 |
| 6 | `scene/World.cpp` | 对象管理、组件调度、JSON 存档 |
| 7 | `scene/Components.cpp` | 反射字段描述（Inspector 的数据来源） |
| 8 | `editor/ImGuiLayer.cpp` → `editor/EditorUI.cpp` | 即时模式 UI、Dock 布局与面板 |
| 9 | `physics/PhysicsWorldSim.cpp` | 积分、碰撞、冲量 |
| 10 | `ai/NavGrid.cpp` → `ai/Agents.cpp` | A\* 与感知/状态机 |
| 11 | `core/JobSystem.cpp` | 分块并行 |

## 6. 目录约定

- `engine/src/<模块>/`：源文件，头文件与实现同目录（学习型工程的取舍：少一层 include 路径）；
- `engine/shaders/`：HLSL，**运行时编译**，改完直接重开 exe 即可生效；
- `engine/assets/scenes/`：编辑器保存的场景 JSON；
- `docs/screenshots/`：各阶段验证截图。
